# FLP 자산관리 (Financial Life Planning)

내 자산 현황을 한눈에 확인하고, 자산 구성과 주요 위험요인을 점검하며, 자산관리 목표와 점검 기준을 세우도록 돕는 개인용 웹앱(PWA)입니다.
데이터는 **이 기기의 브라우저(IndexedDB)에만** 저장되며 서버로 전송되지 않습니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 홈 | 순자산·총자산·부채, 자산 구성(유형별/용도별), 월 현금흐름·저축률(은퇴 후에는 소득 − 지출 = 월 수지, 부족분은 금융자산에서 인출 · 인출률), 종합 재무점수, 주요 점검 사항, 순자산 추이 |
| 투자 점검 | 기대수익률·변동성, 안전형/투자형 비중과 위험성향 적합도, 위험요인 체크리스트(비상금·저축률·부채·DSR·집중도·부동산 편중·유동성·분산. 저축 여력이 마이너스면 비상금이 부족분으로 몇 개월 뒤 바닥나는지 보여 주고 주의 이하로 판정), 위험 대비 수익 지도 |
| 노후 진단 | 몬테카를로 1,000회 시뮬레이션: 은퇴 성공확률, 고갈 시점 분포, 생애 자산 곡선(10~90% 범위, 은퇴 전 저축 여력이 마이너스면 부족분 인출로 은퇴 전부터 줄어든다는 안내), 은퇴 필요자금·준비율, 은퇴 후 월 현금흐름(모든 연금이 나오는 나이 기준 소득 − 지출 = 월 수지, 부족분은 금융자산에서 인출, 목적자금·대출 상환·보험료·일시금은 따로 표시, 연금 생활비 명목 고정이면 월세 등 그 밖의 소득만큼 생활비도 늘려 노후 인출과 같은 금액), 인출률, 생활비 가정 비교, 민감도 표(생활비, 명목 고정 방식이면 월 고정 인출액 300만원 근처~지금 +100만원 50만원 간격 × 은퇴 후 수익률 지금 −2~+3%p, 국민연금 조기·연기 수령. 칸이 많아 한 줄씩 나눠 계산하며 끝날 때까지 빈칸 표시) |
| 처방 실행 | 처방전(저축률·수익률·은퇴나이·생활비 조정안. 저축 여력이 마이너스면 ‘월 476만원 부족 → 월 120만원 저축으로 전환’처럼 부족분 기준으로 보여 줌, 비상금·부채·보장 부족), What-if 슬라이더(월 저축액은 마이너스까지 내려 ‘월 476만원 부족’ 상태도 비교), 저축 여력이 마이너스면 목적자금 처방에 부족분+적립 합계와 비상금 바구니가 바닥나는 시점 안내, 재무목표별 월 적립액, 목적별 자산 바구니, 보장 갭 분석 |
| 노후 인출 | 정액 / 정률 / 3-버킷 / 가드레일 전략 비교, 연금·임대료 등 소득과 은퇴 후 지출 반영, 가드레일과 정액 인출 비교, 생활비 가정 비교, 연금 세금 점검(연금소득세·1,500만 한도·계좌별 연금수령한도), 인출 순서·추가 납입 조합 비교, 종합소득세·건강보험료, 연말결산, 인출용 자산 배치 가이드, 연도별 인출 스케줄(첫해 요약과 표 모두 소득 − 필요 지출 = 수지 → 부족분은 금융자산에서 인출, 일시금·매각·환급은 자산에 더함). 이미 은퇴했으면 현재 자산에서 바로 시작 |
| 데이터·설정 | 프로필(부부 나이·소득·은퇴 나이·국민연금·개인연금, 임대료 등 은퇴 후 소득, 생활비 변화 방식, 퇴직소득세)·자산(명의·수령 연도·연금 재원, 부동산 용도·공동명의·월세·보증금·매각 계획·주택연금)·부채·지출(입력하며 세후 소득 − 지출 = 저축 여력을 바로 보여 주고, 부족하면 ‘매달 X만원 부족’ 안내)·목표(매년 반복 지출 가능)·보험 입력, 점검 기준, CSV 가져오기/내보내기(양식 제공), JSON 전체 백업/복원, 샘플 데이터 |

금액 단위는 **만원**, 비율은 **연 %** 입니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 계산 엔진·CSV 단위 테스트
npm run build      # dist/ 에 배포용 정적 파일 생성
npm run preview    # 빌드 결과 미리보기
```

## GitHub Pages 배포

[.github/workflows/deploy.yml](.github/workflows/deploy.yml)이 `main` 브랜치에 push할 때마다 테스트 → 빌드 → GitHub Pages 배포를 자동으로 실행합니다.

1. GitHub에서 새 저장소를 만듭니다(예: `flp`). 공개 저장소면 무료 계정으로도 Pages를 쓸 수 있습니다. 코드에는 개인 데이터가 들어 있지 않습니다(데이터는 각 기기의 브라우저에만 저장).
2. 이 폴더를 저장소에 올립니다.
   ```bash
   git init
   git add .
   git commit -m "FLP 자산관리 앱"
   git branch -M main
   git remote add origin https://github.com/<내 계정>/flp.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
4. **Actions** 탭에서 `Deploy to GitHub Pages`가 끝나면 `https://<내 계정>.github.io/<저장소 이름>/` 에서 열립니다(대소문자까지 저장소 이름과 같아야 함). (처음에 3번 설정 전에 실행돼 실패했다면 Actions 탭에서 **Re-run**)

경로는 상대경로(`base: './'`)와 해시 라우터를 써서 저장소 이름과 상관없이 동작합니다.

## 휴대폰에서 실행

### 방법 1. 배포 주소로 설치(권장 · PC를 꺼도 됨)

위 ‘GitHub Pages 배포’를 마친 뒤 배포된 주소(HTTPS)에 휴대폰 브라우저로 접속해
- 안드로이드 Chrome: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- iPhone Safari: 공유 → **홈 화면에 추가**

설치하면 홈 화면 아이콘으로 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다. Netlify·Cloudflare Pages 등 다른 정적 호스팅을 쓰려면 `npm run build`로 만든 `dist/` 폴더를 올리면 됩니다.

### 방법 2. 같은 와이파이에서 PC 개발 서버로 열기(잠깐 확인용)

```bash
npm run dev -- --host
```

터미널에 나오는 `Network: http://192.168.x.x:5173/` 주소를 휴대폰 브라우저에 입력합니다. PC와 휴대폰이 같은 와이파이에 있어야 하고, Windows 방화벽이 묻으면 ‘개인 네트워크’ 허용을 누릅니다. HTTPS가 아니어서 앱 설치·오프라인 동작은 되지 않고, PC 서버를 끄면 열리지 않습니다.

### 데이터 옮기기

데이터는 기기(브라우저)마다 따로 저장됩니다. PC에서 입력한 데이터를 휴대폰에서 쓰려면
1. PC: ‘데이터·설정 → 가져오기·백업 → 전체 백업·복원 → 백업 파일 받기’로 `FLP_백업_날짜.json` 파일을 받습니다.
2. 파일을 휴대폰으로 옮깁니다(본인에게 보내는 메신저·클라우드 드라이브·USB 등). 개인 금융 정보이니 남에게 공유되는 곳에는 올리지 마세요.
3. 휴대폰: 앱을 열고 ‘데이터·설정 → 가져오기·백업 → 백업에서 복원’을 눌러 그 파일을 고릅니다. 복원하면 휴대폰에 있던 데이터는 백업 내용으로 바뀝니다.

휴대폰과 PC에서 따로 고치면 서로 맞춰지지 않습니다. 한쪽을 기준으로 정해 고치고, 바꾼 뒤에는 다시 백업 → 복원으로 옮기세요. 브라우저 데이터 삭제·앱 삭제 시 데이터도 지워지니 백업 파일을 보관해 두세요.

## 주요 기능 사용법

### 부부 소득·연금
‘데이터·설정 → 프로필’에서 배우자 출생연도를 넣으면 배우자 세후 소득·은퇴 나이·국민연금(개시 나이·월액)·개인연금을 **배우자 나이 기준**으로 입력할 수 있습니다. 계산할 때는 본인 나이로 바꿔, 배우자가 먼저 은퇴하면 그때부터 저축이 줄고 본인이 먼저 은퇴하면 배우자 은퇴 전까지 배우자 소득을 은퇴 후 소득으로 넣습니다. 자산의 ‘명의’(본인/배우자)는 연금 세금을 사람별로 계산할 때 씁니다.

‘개인·퇴직연금 월액’은 계좌 잔액과 별개로 정해진 금액이 나오는 연금(종신형 연금보험 등)만 넣습니다. 연금저축·IRP·퇴직연금 계좌 잔액은 자산 탭에 넣으면 노후 인출에서 꺼내 쓰므로, 같은 계좌의 월 수령액을 또 넣으면 두 번 계산됩니다. 월액이 0보다 크고 자산 탭에 연금 계좌(본인 칸은 본인·공동명의, 배우자 칸은 배우자·공동명의)가 있으면 그 칸 아래에 경고가 나옵니다.

국민연금은 생일 다음 달부터 나오므로, 본인·배우자 **출생 월**을 넣으면 개시 첫해를 그만큼만(예: 7월생 → 5개월) 계산합니다. **국민연금 연 인상률**(명목)을 넣으면 물가 대신 그 비율로 오르고, 물가보다 낮으면 실질 수령액이 해마다 조금씩 줄어듭니다.

### 그 밖의 은퇴 후 소득
프로필의 ‘그 밖의 은퇴 후 소득’에 **은퇴 뒤에** 들어오는 임대료·근로소득·사업소득 등을 시작·종료 나이, 오늘 기준 월액, 인상 주기·인상률과 함께 추가합니다(‘+ 소득 추가’를 누르면 이름 ‘기타 소득’, 종류 ‘그 밖’으로 시작). 누구 나이 기준인지(본인/배우자)도 고를 수 있습니다.

- **은퇴 전 소득**은 여기가 아니라 프로필의 ‘세후 월소득(가구)’에 합쳐 넣습니다(지금 받는 월세 포함). 종합소득세 계산용 세전 급여는 ‘은퇴 전 세전 총급여’ 칸에 따로 넣습니다.
- 종류가 **임대소득**인 항목의 이름이 자산 탭 임대용 부동산과 비슷하거나 월액이 같으면, 같은 월세를 두 번 넣었을 수 있다는 경고가 그 항목에 나옵니다.
- **국민연금·개인·퇴직연금**은 프로필의 전용 칸에 넣습니다. 임대용 부동산 월세는 ‘자산’ 탭에서 넣으면 자동 반영됩니다. 같은 돈을 여기에 또 넣으면 두 번 계산됩니다.
- **소득 종류**를 고르면 종합소득세·건강보험료 추정에 종류대로 들어갑니다. 임대소득 = 임대 필요경비율 차감(배우자 몫은 설정값), 근로소득 = 근로소득공제(한도 2,000만)·근로소득세액공제·표준세액공제 13만, 연말정산으로 낸 세금은 기납부로 빼서 5월 추가납부는 다른 소득과 합쳐 늘어난 만큼만·건보료는 총급여 × 반영률(지역가입자 50%), 사업소득 = 항목별 필요경비율 차감·건보료 100%, 공적연금(공무원·사학·군인) = 국민연금과 합쳐 연금소득공제·건보료 × 반영률, 사적연금 = 종소세 제외(1,500만 이하 분리과세)·건보료는 ‘사적연금도 반영’일 때만, 그 밖 = 세금 계산 제외. 임대 외에는 ‘나이 기준’으로 고른 사람의 소득으로 봅니다. 예전에 ‘임대소득’을 체크한 항목은 임대소득으로 읽습니다.

### 생활비 가정 비교
노후 진단·노후 인출의 ‘생활비 가정 비교’ 표에서 세 가지 가정의 성공확률·고갈 나이·월 생활비 변화를 함께 봅니다.
- **물가 연동**: 생활비가 물가만큼 올라 생활 수준을 그대로 유지
- **생활비 명목 고정**: 생활비 금액을 그대로 둠(실제 가치는 물가만큼 줄어듦)
- **연금 생활비 명목 고정(엑셀 방식)**: ‘연금계좌 인출 + 국민연금’으로 쓰는 금액을 고정. 국민연금이 나오면 그만큼 계좌 인출이 줄고, 임대료 등은 따로 모두 씀

계산에 쓸 가정은 ‘프로필 → 노후 계획 → 은퇴 후 생활비 변화’에서 고릅니다.

같은 카드의 **나이 구간별 생활비**에서 ‘70세부터 월 330만원’처럼 나이마다 월 생활비(오늘 물가 기준)를 바꿀 수 있습니다. 활동이 많은 은퇴 초기에는 더 쓰고 나이가 들수록 덜 쓰는 흐름을 반영하며, 은퇴~첫 구간 전은 은퇴 후 월 생활비를 씁니다(은퇴 나이 이전에 시작하는 구간은 은퇴부터 적용). 계산에는 기본 생활비 대비 배율로 넣어, 처방·민감도 분석에서 생활비를 바꿔 볼 때 구간도 같은 비율로 따라갑니다. 물가 연동·명목 증가율 방식과 함께 쓰며, ‘연금 생활비 명목 고정’ 방식에서는 쓰지 않습니다. 노후 진단의 월 현금흐름·가정과 노후 인출에 구간별 생활비가 반영됩니다.

### 부동산(거주용·임대용·투자용)
부동산 자산은 금융자산의 ‘용도·성격·변동성’ 대신 **부동산 용도**와 **연 시세 상승률**을 입력합니다. 부동산은 매일 사고팔 수 없어 노후 시뮬레이션의 운용자산에서 빠지므로 변동성은 쓰지 않습니다.
- **거주용**: 팔기 전까지는 순자산·부동산 편중 점검에만 들어갑니다. 시세 상승률은 장기 물가 + 0~1%p 정도(예: 2.5~3.5%)를 넣고, 매각 연도를 넣었을 때만 매각대금 계산에 씁니다. 다운사이징이면 **새 집 구입액**(오늘 시세)을 넣으면 그만큼 빼고 들어옵니다.
- **임대용**: **월세·임대보증금·계약 갱신 주기·갱신 때 인상률·공실·관리 경비율**을 넣습니다. 보증금은 돌려줄 돈이라 부채(순자산·부채비율)에 들어가고, 경비를 뺀 월세는 은퇴 후 소득으로(갱신 주기마다 인상, 매각 전 해까지) 노후 진단·인출에 반영됩니다. 은퇴 전 월세는 세후 월소득에 넣고, ‘그 밖의 은퇴 후 소득’에 같은 월세를 또 넣지 마세요.
- **주택연금**(거주용): **가입 나이**(본인 기준)를 넣으면 그 나이의 예상 시세와 부부 중 연소자 나이로 월 수령액을 자동 추정합니다(한국주택금융공사 2026.3 월지급금 예시, 일반주택·종신 정액형, 주택가격 12억까지·연령별 최대 지급액). 공사 조회 금액이 있으면 **월 수령액**(오늘 기준)에 직접 넣으세요. 정액형이라 가입 뒤 명목 금액이 평생 같고(실질로는 물가만큼 줄어듦), 노후 진단·인출의 연금 소득으로 들어갑니다. 대출 형식이라 종합소득세·건강보험료 대상이 아니며, 주택연금을 쓰면 매각 계획은 쓰지 않습니다. 부부 중 한 명이 55세 이상이어야 반영합니다. 기대수명까지 받았을 때의 대출 잔액(월지급금 + 이자 + 보증료, 기본 금리 3.8% = COFIX+0.85%p 가정 · 초기보증료 1.0% · 연보증료 0.95%이며 자산의 **대출 금리·초기보증료·연보증료** 칸에서 바꿀 수 있음)을 예상 시세에서 뺀 **상속 시 남는 주택 가치**를 자산 설명과 노후 진단 가정에 보여 줍니다(순자산·부채에는 넣지 않는 참고 값).
- **투자·기타**(토지·분양권 등): 매각 연도에 시세차익을 실현하는 자산으로 봅니다.
- **명의**: 본인·배우자·**공동명의(본인 지분 %)**. 임대용 부동산 월세의 종합소득세·건강보험료를 지분대로 나눠 계산합니다.
- **매각 연도·매각 비용률**: 매각 연도의 예상 시세 − 매각 비용(양도세·중개보수 실효율, 1주택 비과세면 0.5% 안팎) − 보증금 반환 − 새 집 구입액이 그해 금융자산(ISA·일반계좌)으로 들어와 함께 운용됩니다. 0이면 계속 보유합니다.
- 홈 ‘용도별’ 자산 구성에는 부동산이 용도별로 따로 나오고, 투자 점검의 용도별 배치·처방의 목적별 바구니·목적자금 배정은 금융자산만으로 계산합니다.

### 수령 시점이 정해진 자산(노란우산 등)
자산의 ‘명의·수령 시점’ 설정에서 **수령 연도**와 **수령 시 세율**을 넣으면 그 전까지는 인출 계산에서 빠지고 기대수익률로 불어난 뒤, 수령 연도에 세후 일시금으로 들어와 다른 금융자산과 함께 운용됩니다.

### 연금 세금 점검
연금계좌 자산마다 **과세제외**(세액공제 안 받은 원금), **퇴직금 재원**, **연금수령 1년차 연도**를 넣고, 프로필 ‘연금 세금’에 퇴직소득세 실효세율과 퇴직금 연금 실수령 1년차를 넣습니다. 노후 인출의 ‘연금 세금 점검’ 카드가 보여 주는 것:
- 첫해 세전 인출·세금, 계획 기간 세금 합계, 세금을 반영한 자산 고갈 나이
- 1인 연 1,500만원(세전, 명목) 분리과세 한도를 넘는 해
- 계좌별 연금수령연차·연금수령한도·인출액과, 한도를 넘는 계좌 경고
연도별 인출 스케줄에는 세금·세전 인출·한도 사용액 열이 추가되고, 한도를 넘는 해는 노란색으로 표시됩니다.

연금 자산마다 넣을 수 있는 인출 설정:
- **인출 시작 연도**: 그 전에는 꺼내지 않습니다(추가 납입을 받는 계좌로 남겨 둘 때). 연금수령연차는 ‘연금수령 1년차 연도’부터 그대로 셉니다.
- **꺼내는 순서**: 같은 사람 계좌 중 작은 번호부터 꺼냅니다(예: 연금저축 먼저 1, IRP 2).
- **비교 기준 순서**: 노후 인출의 ‘인출 순서·추가 납입 비교’ ① 조합에서만 쓰는 순서입니다. 모두 0이면 ①은 자산 목록 순서를 씁니다.

### 1,500만 한도 꽉 채우기
‘프로필 → 연금 세금’에서 ‘1,500만 한도 매년 꽉 채우기’를 ‘예’로 고르면, 시작 연도부터 생활비보다 많더라도 해마다 1인 1,500만원까지 과세재원을 낮은 세율(5.5~3.3%)로 미리 꺼내 세후 금액을 ISA·일반계좌에 다시 넣습니다. 인출 스케줄의 ‘ISA 재투자’ 열에 재투자액·납입액·연말 잔액이 나옵니다.

### 연금계좌 추가 납입(세액공제)
‘프로필 → 연금계좌 추가 납입’에 본인·배우자 연 납입액과 기간을 넣습니다. 납입금은 ISA·일반계좌에서 먼저 내고(모자라면 연금계좌에서 더 꺼냄), 본인 납입은 인출 시작 전 본인 계좌로 들어갑니다. 세액공제는 1인 연 900만원까지 × 공제율(종합소득금액 4,500만원 이하 16.5%, 초과 13.2%, 직접 입력 가능)이고, 종합소득세 추정을 켜면 그해 종합소득세까지만 공제합니다. 환급금은 다음 해 들어와 노후 진단·인출에 반영되고, 공제받지 못한 납입액은 과세제외 금액이 됩니다.

### 인출 순서·추가 납입 비교
노후 인출의 ‘인출 순서·추가 납입 비교’ 카드에서 다섯 가지 조합을 나란히 봅니다. ① 계좌별 비교 기준 순서(없으면 자산 목록 순서)로 모든 연금계좌를 바로 인출 · 납입 없음, ② 계좌별 꺼내는 순서·인출 시작 연도 적용 · 납입 없음, ③ ② + 본인 추가 납입, ④ ② + 본인·배우자 추가 납입, ⑤ ② + 배우자 추가 납입만. 조합마다 세금 합계, 세액공제 환급, 순 세금, 1,500만 한도를 넘는 연도와 16.5%로 꺼낸 금액, 연금수령한도 초과 계좌, 세금을 반영한 고갈 나이를 계산합니다. 계획이 90세를 넘으면 90세까지 세금 합계와 90세 연말 잔액(세금 반영, 오늘 물가)도 보여 줘서, 모든 조합이 마지막 해에 바닥나도 차이를 비교할 수 있습니다. 카드 위 납입액·기간은 비교에만 쓰이고, 계획에 넣으려면 ‘프로필 → 연금계좌 추가 납입’에 입력합니다.

### 종합소득세·건강보험료
‘그 밖의 은퇴 후 소득’에서 임대료 항목의 **임대소득**을 체크하고, ‘프로필 → 종합소득세·건강보험료’를 ‘추정하기’로 바꾼 뒤 임대소득 배우자 몫·필요경비율, 국민연금 과세대상 비율, 소득공제, 현재 월 건강보험료(고지서)를 넣습니다. 아직 일하고 있으면 ‘프로필 → 부부 소득·연금’의 **은퇴 전 세전 총급여(연, 오늘 기준)**를 본인·배우자 각각 넣습니다. 각자 은퇴 전 해까지 이 급여를 근로소득으로 월세 등 다른 소득과 합쳐 세율 구간·근로소득세액공제·표준세액공제를 계산하고, 회사 연말정산으로 낸 세금(급여만 있다고 본 결정세액)은 기납부로 빼서 5월 추가납부에는 월세 등 때문에 늘어난 세금만 들어갑니다. 건보료는 직장에서 낸다고 보고 지역 건보료에는 넣지 않고, 저축·노후 계산에는 쓰지 않습니다(그쪽은 세후 월소득). **건보료 재산분**을 ‘부동산 자산으로 추정’으로 바꾸면 고지서 대신 부동산 자산의 해마다 오르는 시세 × 시세 대비 공시가격 비율(기본 69%) × 공정시장가액비율(주택 60%)로 세대 재산 과세표준을 구하고, 기본공제 1억을 뺀 금액의 재산등급 점수(시행령 별표4) × 211.5원(2026년)으로 연도별 재산분을 추정합니다. 부부 한 세대 합산이라 명의·지분과 상관없고, 매각 연도부터는 빠지며(주택연금 주택은 계속 포함), 임대보증금은 집주인 재산에서 빼지 않습니다(세입자의 전월세 재산으로 잡힘). **주택 구입 대출 공제**를 ‘예’로 하면 부채 탭에서 ‘실거주 주택 구입 대출’로 표시한 대출의 해마다 줄어드는 잔액(원리금 균등 상환) × 60%를 5,000만 한도로 재산 과세표준에서 빼고, 그 해 주택(거주용·임대용)이 2채 이상이면 빼지 않습니다(실제로는 공시가격 5억 이하 주택을 취득 전후 3개월 안에 빌린 대출이어야 하고 공단에 신청해야 함). 대출 표시는 1세대 1주택으로 지금 사는 집을 사려고 받은 대출(주택담보대출·보금자리론 등)에만 하고, 전세자금대출·신용대출·투자용 주택 대출은 표시하지 않습니다. 표시했는데 ‘추정하기’·‘부동산 자산으로 추정’·‘주택 구입 대출 공제’ 중 꺼진 것이 있으면 부채 카드에 무엇을 바꿔야 반영되는지 안내합니다. 프로필의 ‘주택 구입 대출 공제’ 항목 아래에는 표시한 대출 이름·잔액과 올해 공제액(잔액 × 60%, 한도 5,000만, 2주택이면 0)이 나옵니다. 노후 인출의 ‘종합소득세·건강보험료’ 표 ‘대출 공제’ 열에는 해마다 빠지는 공제액이 나오고, 공제가 처음 0이 되는 해(상환 끝 또는 2주택)는 ‘0 (공제 끝)’으로 강조하고 표 아래에 그 해를 적습니다. 자동차와 전월세 임차 대출은 넣지 않습니다. 노후 인출의 ‘종합소득세·건강보험료’ 카드에 연도별 종합소득세(본인/배우자)·5월 추가 납부·월 건보료·연 부담과, 첫해보다 늘어나는 금액 중 국민연금 몫이 나옵니다. 은퇴 전 급여를 넣었다면 ‘기준 해 대비’로 바뀌어, 급여가 있는 해는 첫해와, 급여가 모두 끝난 해(은퇴 후 첫해)부터는 그 해와 비교합니다(급여가 빠져 세금이 줄어든 것을 감소로 보이지 않게). ‘늘어난 세금 인출에 더하기’를 고르면 국민연금 몫만큼 해마다 자산에서 더 꺼내는 것으로 노후 진단·인출을 다시 계산합니다.

### 가드레일 비교와 연말결산
노후 인출에서 가드레일 폭·조정 폭·‘감액만’을 바꾸며 정액 인출과 자산 유지 확률·고갈 나이를 비교합니다. 계획을 정하면 연말결산 카드의 ‘지금 계획을 기준선으로 고정’을 누르고, 해마다 12월 말 실제 금융자산(수령 전 노란우산 등은 빼고)과 그해 인출액을 ‘연말결산’에 기록하면 기준선과 비교해 다음 해 권장 인출액을 알려 줍니다.

### 백업과 복원
‘데이터·설정 → 가져오기·백업’에서
- **전체 백업·복원(JSON)**: ‘백업 파일 받기’ / ‘백업에서 복원’. 프로필·자산·목표·연말결산 등 모든 데이터를 파일 하나로 저장하고 되살립니다. 기기를 옮기거나 브라우저 데이터를 지우기 전에 꼭 받아 두세요.
- **CSV 가져오기/내보내기**: 표 하나씩(자산·부채 등) 엑셀로 편집할 때 씁니다. 자산 CSV에는 기본 열 뒤에 **명의·수령·매각 연도·수령 세율·매각 비용률**과 부동산 전용 열(용도·본인 지분·월세·임대보증금·갱신 주기·인상률·경비율·새 집 구입액·주택연금 가입 나이·월 수령액·대출 금리·초기보증료·연보증료)이 선택 항목으로 붙고, 부동산이 아닌 행의 부동산 열은 빈칸입니다. 부채 CSV에는 선택 열 **상환 방식**(‘만기일시’·‘원금균등’ 또는 빈칸 = 원리금균등)과 **건보 대출 공제**(‘주택 구입’ 또는 빈칸)가 붙습니다. 보험 CSV에는 **납입 종료 나이** 열과 선택 열 **피보험자**(‘본인’·‘배우자’·‘자녀’ 또는 빈칸 = 본인)·**자녀 출생연도**가 있으며, 납입 종료 나이 열이 없는 예전 파일은 0(계속 납입)으로 읽습니다. 양식 파일을 받아 채운 뒤 ‘기존 데이터에 추가’ 또는 ‘기존 데이터를 지우고 교체’를 골라 가져옵니다.

## 계산 방식 요약

- **목표 현가화**: 현재가치 금액 × (1+비용상승률)^년수 = 미래 필요액 → ‘중기·목적자금’ 자산을 시기가 빠른 목표부터 배정 → 부족분을 월 적립액(PMT)으로 산출
- **몬테카를로**: 연 수익률 ~ 정규분포(금액가중 기대수익률, 변동성), 물가를 뺀 실질 기준, 시드 고정으로 재현 가능. 은퇴 전 저축 적립, 목표 시점 목적자금 지출, 은퇴 후 (생활비 − 연금 + 남은 대출 상환) 인출. 부동산은 거주용으로 보고 제외
- **은퇴 후 자산 운용**: 프로필에서 ‘따로 입력’을 고르면 은퇴 나이부터 따로 입력한 기대수익률·변동성을 노후 진단·노후 인출에 적용. 변동성 칸에는 수익률에 맞는 권장 범위(예금 금리 약 3%를 넘는 초과수익 1%마다 2.5~5%: 4% → 2.5~5%, 6% → 7.5~15%, 8% → 12.5~25%)가 나오고, 범위보다 낮으면 성공확률이 낙관적으로 나온다는 경고, 높으면 보수적이라는 안내가 나옴. 경고 옆 ‘권장값으로 맞추기’를 누르면 은퇴 후 변동성을 권장 범위의 가운데 값(0.5% 단위)으로 바꿈
- **대출 상환 종료**: 상환 종료 나이(비우면 잔액·금리·월상환액으로 원리금 균등 상환 기간 계산)가 은퇴 전이면 그 뒤로 월 상환액만큼 저축이 늘고, 은퇴 후까지 이어지면 남은 기간 동안 인출액에 더함(상환액은 현재 금액 그대로 가정)
- **대출 연도별 상환**: 노후 진단 화면에 대출별 연 상환액·연말 잔액 표(상환 방식·금리 표시, 은퇴 나이 행 강조)가 나옵니다. 지금 월 상환액·잔액·금리로 추정한 물가 반영 전 금액이며, 원금균등은 해마다 줄고 만기일시는 만기 나이에 ‘원금 일시 상환’으로 표시합니다. 끝나지 않는 대출은 기대수명까지 보여 줍니다
- **원금균등 상환**: 부채의 상환 방식을 ‘원금균등 상환’으로 바꾸고 월 상환액에 이번 달 낸 금액(원금 + 이자)을 넣습니다. 월 원금 = 상환 종료 나이가 있으면 잔액 ÷ 남은 개월, 없으면 월 상환액 − 이번 달 이자이고, 잔액은 해마다 월 원금 × 12만큼 줄어 잔액 ÷ 월 원금 개월 뒤 끝납니다. 이자가 줄어 월 상환액이 해마다 월 원금 × 12 × 월 금리만큼 줄고, 은퇴 전에는 줄어든 만큼 저축이 늘며 은퇴 후에도 남으면 그 해 상환액을 자산에서 인출합니다
- **만기일시 상환**: 부채의 상환 방식을 ‘만기일시 상환’으로 바꾸면 월 상환액(이자)은 만기 전 해까지 내고, 상환 종료 나이(만기)에 남은 원금을 자산에서 한 번에 갚습니다. 원금은 명목 금액이 그대로라 실질 금액 = 원금 ÷ (1 + 물가)^(만기까지 햇수)로 빠지며, 만기 나이가 없으면 원금 상환을 반영하지 않습니다(부채 카드 테두리와 안내 문구를 경고색으로 표시하고 문구를 누르면 상환 종료 나이 입력칸으로 이동, 홈 주요 점검 사항 맨 앞·투자 점검 위험요인 체크리스트·처방전에 ‘만기 나이 입력 필요’ 경고, 재무점수에는 넣지 않음). 처방전에는 만기 원금이 평균 수익 가정에서 그 해 초 금융자산의 몇 %인지와 상환 뒤 잔액이 나오며(상환 뒤 0이면 위험, 50% 초과면 주의), 노후 인출의 연도별 스케줄에는 그 해 필요 지출 아래 ‘대출 원금 상환’으로 따로 표시합니다
- **이미 은퇴한 경우**: 현재 나이가 은퇴 나이 이상이면 저축 없이 지금 금융자산에서 바로 인출을 시작(필요자금·인출률·노후 인출 모두 현재 나이 기준)
- **은퇴 후 소득**: 국민연금·배우자 국민연금(배우자 나이를 본인 나이로 환산)·개인연금은 실질 금액 일정(국민연금 연 인상률을 넣으면 명목 그 비율로 오르고 물가로 할인, 출생 월을 넣으면 첫해는 생일 다음 달부터 월할). 임대료 등은 오늘 기준 월액에 ‘인상 주기마다 인상률’을 적용하고 물가로 할인
- **월 저축 여력** = 세후 소득 − 지출(고정·변동) − 대출 월 상환액 − 보험 탭 월 보험료 합계. 마이너스면 은퇴 전에도 그 부족분을 해마다 금융자산에서 꺼내는 것으로 계산하고(0으로 자르지 않음), 홈 화면에 안내가 나옵니다. 연금 계좌·투자 자산에서 꺼내 쓰는 돈은 세후 소득에 넣지 않습니다. 은퇴 나이가 지나면 홈의 월 현금흐름은 노후 진단과 같은 방식(은퇴 후 월 생활비 + 대출 − 연금·소득 = 금융자산에서 인출, 인출률·상한)으로 바뀌고, 지출 탭과 세후 월소득은 쓰지 않습니다. 지출 항목 이름·분류에 ‘보험’이 들어간 항목이 있으면 보험료가 이미 들어 있다고 보고 보험 탭 금액은 더하지 않으며, 지출 화면에 중복 의심 안내가 나옵니다. 보험마다 **피보험자**(본인·배우자·자녀)를 고르고 **납입 종료 나이**를 그 사람 나이로 넣습니다. 배우자는 기본 정보의 배우자 출생연도, 자녀는 보험에 넣은 자녀 출생연도로 본인 나이로 바꿔 계산하며(출생연도가 없으면 본인 나이로 봄), 보험 카드 아래에 ‘배우자 60세 = 본인 62세’처럼 함께 보여 줍니다. 납입 종료 나이를 넣으면 그 나이부터 보험료가 지출에서 빠지고, 은퇴 전에 끝나면 그 나이부터 월 보험료만큼 은퇴 전 저축이 늘어나는 것으로 계산하며 처방전에 ‘보험 납입 완료 후 저축 증가’가 나옵니다. 납입 종료 나이가 은퇴 나이보다 늦으면 은퇴(이미 은퇴했으면 지금)부터 종료 전 해까지 보험료를 매년 자산에서 꺼내는 것으로 계산하며(명목 고정이라 실질 = 연 보험료 ÷ (1 + 물가)^햇수), 노후 진단의 월 현금흐름·가정과 노후 인출 스케줄에 ‘보험료’로 표시합니다. 0이면 은퇴 후 보험료는 은퇴 후 생활비에 들어 있다고 봅니다. 지출에 보험료 항목이 따로 있으면 이 두 가지를 반영하지 않으며, 지출 화면의 중복 경고에서 ‘지출에서 이 항목 지우기’를 누르면 그 항목을 지우고 보험 탭 금액이 자동으로 더해집니다. 노후 진단의 월 현금흐름 카드 아래 **은퇴 전 저축 변화**에 보험 납입 완료(‘자녀 실손 납입 완료 (자녀 20세 · 본인 50세)’)·배우자 은퇴·대출 상환 완료로 저축이 바뀌는 나이와 월 금액을 보여 줍니다
- **반복 지출**: 재무목표에 반복 종료 나이를 넣으면 시작~종료 나이까지 매년 지출(노후 진단·인출에 반영, 목적자금 적립 계산에서는 제외)
- **인출률**: 인출 첫해 자산에서 꺼내는 금액(생활비 − 연금·소득 + 남은 대출 + 그해 지출) ÷ 금융자산. 상한(기본 6%)의 2/3 이하 양호, 상한 이하 주의, 초과 위험
- **가드레일 인출**: 평균수익으로 정액 인출할 때의 연초 자산을 기준선으로, 매년 초 자산이 기준선보다 ±15% 넘게 벗어나면 인출을 10% 줄이거나 되돌림(계획의 70~130%, 기본은 ‘감액만’)
- **연말결산**: ‘기준선으로 고정’ 시점의 평균수익·정액 인출 경로를 물가로 환산해 해마다 12월 말 실제 자산과 비교. 판정은 1년에 한 번, 직전 배율에서 이어서 적용
- **연금 세금**: 과세제외 → 과세재원(1인 연 1,500만원 안, 연금소득세 5.5·4.4·3.3%) → 퇴직금 재원(퇴직소득세 × 70%, 11년차부터 60%) → 계좌 밖 자산 → 1,500만 초과분(16.5%) 순으로 꺼냄. 계좌별 **연금수령한도** = 연초 평가액 ÷ (11 − 연금수령연차) × 120%(11년차부터 한도 없음, 1년차 = 55세·가입 5년이 지난 해). 한도를 넘는 금액은 연금외수령(과세재원 16.5%, 퇴직금 재원 퇴직소득세 전액)으로 보고 경고
- **인출 시작·순서와 한도 채우기**: 계좌별 인출 시작 연도 전에는 꺼내지 않고, 같은 사람 계좌는 ‘꺼내는 순서’대로 꺼냄. ‘꽉 채우기’를 켜면 필요액을 꺼낸 뒤 남은 1,500만 한도·연금수령한도 안에서 과세재원을 더 꺼내 세후 금액을 ISA·일반계좌(같은 수익률로 운용)에 넣음
- **추가 납입**: 납입은 ISA·일반 → (모자라면) 연금계좌 인출 순으로 내고, 공제받은 납입액은 과세재원, 나머지는 과세제외로 쌓음. 세액공제 = min(납입, 900만) × 공제율, 종소세 추정을 켜면 그해 종소세가 한도. 환급은 다음 해 실질 금액으로 유입
- **종합소득세·건보료**: 임대 사업소득 = 임대수입 × (1 − 필요경비율), 공적연금 연금소득금액 = 총연금액 − 연금소득공제(한도 900만), 근로소득금액 = 총급여 − 근로소득공제(한도 2,000만), 근로소득세액공제 = 근로소득분 산출세액(산출세액 × 근로소득금액 ÷ 종합소득금액) 130만 이하 55% · 넘는 부분 30%(한도 총급여 3,300만 이하 74만 · 7,000만 이하 66~74만 · 1.2억 이하 50만 · 그 초과 20만 이상)에 표준세액공제 13만, 근로 원천징수(기납부) = 근로소득만 있다고 본 연말정산 결정세액, 사업소득 = 수입 × (1 − 항목별 필요경비율), 종합소득세 = 2023년~ 누진세율 × 1.1(지방세). 건보료 = (전년 임대·사업소득 + 전년 (공적연금 + 근로소득 총급여) × 50%) × 보험료율 + 재산분(현재 고지서에서 역산, 또는 부동산 자산 과세표준 − 1억의 등급 점수 × 211.5원) × (1 + 장기요양). 국민연금 몫 = 국민연금 때문에 늘어난 종소세(원천징수 뺌) + 건보료 소득분. 국민연금은 입력 월액(세후면 세전으로 환산)이 연 인상률(비우면 물가)만큼 오른다고 보고, 개시 첫해는 출생 월 다음 달부터 월할
- **부부**: 배우자 출생연도·세후 소득·은퇴 나이·국민연금·개인연금을 배우자 나이로 입력하면 본인 나이로 바꿔 계산. 배우자가 먼저 은퇴하면 그때부터 저축 감소, 본인이 먼저 은퇴하면 배우자 은퇴 전까지 배우자 소득을 은퇴 후 소득으로 반영
- **인출률 기준**: 투자 점검·노후 진단·노후 인출 모두 기본값은 ‘평균수익 가정 인출 시작 시점 금융자산’(은퇴자는 현재 금융자산) 기준
- **소득 인상**: 인상률은 1회 인상률(예: 2년마다 5%)
- **국민연금 개시 나이 비교**: 입력 월액을 입력한 개시 나이 기준으로 보고 1년 조기당 6% 감액, 1년 연기당 7.2% 증액(최대 5년)
- **처방**: 성공확률 목표를 맞추는 저축액·수익률·은퇴나이·생활비를 이분 탐색으로 역산
- **보장 갭**(피보험자별): 보험을 피보험자(본인·배우자·자녀 출생연도별)로 묶어 따로 진단합니다. 본인 사망보장 = 유족 생활비 × 부양기간 + 부채 + 교육비 − 유동자산, 진단비 = 그 사람 연소득(본인 = 가구 소득 − 배우자 소득) × N배(소득이 없으면 3,000만원), 배우자 사망보장 = 배우자 연소득 × 부양기간, 자녀는 진단비 3,000만원만 필요액으로 보고 사망·간병은 가입한 경우에만 표시합니다. 처방전에는 ‘배우자 암·중대질병 진단비 부족’처럼 사람 이름을 붙입니다
- **재무점수(100)**: 저축률 20 · 비상금 15 · 부채 15 · 노후 준비 25 · 분산·적합 10 · 보장 15 (매달 부족분으로 비상금이 줄고 있으면 비상금 점수는 목표 개월 수 안에 바닥날 때 40%, 아니면 60%가 상한)

> 계산 결과는 입력값과 가정에 기반한 참고용 추정치이며, 투자 권유나 금융 자문이 아닙니다.
