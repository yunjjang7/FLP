# FLP 자산관리 (Financial Life Planning)

내 자산 현황을 한눈에 확인하고, 자산 구성과 주요 위험요인을 점검하며, 자산관리 목표와 점검 기준을 세우도록 돕는 개인용 웹앱(PWA)입니다.
데이터는 **이 기기의 브라우저(IndexedDB)에만** 저장되며 서버로 전송되지 않습니다.

## 화면

| 화면 | 내용 |
| --- | --- |
| 홈 | 순자산·총자산·부채, 자산 구성(유형별/용도별), 월 현금흐름·저축률(은퇴 후에는 소득 − 지출 = 월 수지, 부족분은 금융자산에서 인출 · 인출률), 종합 재무점수, 주요 점검 사항, 순자산 추이 |

| 인출 계획 | 정액 / 정률 / 3-버킷 / 가드레일 전략 비교, 연금·임대료 등 소득과 은퇴 후 지출 반영, 가드레일과 정액 인출 비교(감액 판정은 기준선과 필요 자산 중 낮은 쪽), 노후 진단의 생활비 가정 비교로 가는 바로가기, 연금 세금 점검(연금소득세·1,500만 한도·계좌별 연금수령한도, 계좌별 인출 지시: 증권사 정기지급으로 걸 월 세전 금액·세금·세후·한도 사용률), 월별 실제 인출 기록(계좌별 계획 대비·연 누적 한도 초과 표시·CSV), 수익률 시나리오별 80·90·100세 잔액과 목돈 지출 민감도, 인출 순서·추가 납입 조합 비교, 종합소득세·건강보험료, 연말결산(계획 대비 실제 자산·실제 수익률 추정), 인출용 자산 배치 가이드(전체 + 계좌별 현금성·채권·성장·대체 목표, 시장 등락률에 따른 규칙), 다가오는 이정표·올해·내년 할 일, 연도별 인출 스케줄(첫해 요약과 표 모두 소득 − 필요 지출 = 수지 → 부족분은 금융자산에서 인출, 일시금·매각·환급은 자산에 더함). 이미 은퇴했으면 현재 자산에서 바로 시작하고 올해는 남은 달만큼만 계산 |
| 기본 정보 | 프로필(부부 나이·소득·은퇴 나이·국민연금·개인연금, 임대료 등 은퇴 후 소득, 생활비 변화 방식, 퇴직소득세)·자산(명의·수령 연도·연금 재원, 부동산 용도·공동명의·월세·보증금·매각 계획·주택연금, 시세가 가입 기준을 넘으면 경고)·부채·지출(입력하며 세후 소득 − 지출 = 저축 여력을 바로 보여 주고, 부족하면 ‘매달 X만원 부족’ 안내)·목표(매년 반복 지출 가능)·보험 입력, 점검 기준, CSV 가져오기/내보내기(양식 제공), JSON 전체 백업/복원, 샘플 데이터 |

금액 단위는 **만원**, 비율은 **연 %** 입니다. 숫자 입력칸은 천 단위 콤마(예: 12,000)로 보여 주고, 콤마 없이 쳐도 됩니다(연도 칸은 콤마 없이). PC에서는 칸에서 ↑·↓ 키로 칸마다 정해진 간격(금액 1, 비율 0.1 등)만큼 올리고 내릴 수 있습니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 계산 엔진·CSV 단위 테스트
npm run build      # dist/ 에 배포용 정적 파일 생성
npm run preview    # 빌드 결과 미리보기
```

## GitHub Pages 배포

[.github/workflows/deploy.yml](.github/workflows/deploy.yml)이 `main` 브랜치에 push할 때마다 테스트 → 빌드 → GitHub Pages 배포를 자동으로 실행합니다.

1. GitHub에서 새 저장소를 만듭니다(예: `flp`). 공개 저장소면 무료 계정으로도 Pages를 쓸 수 있습니다. 코드에는 개인 데이터가 들어 있지 않습니다(데이터는 각 기기의 브라우저에만 저장).
2. 이 폴더를 저장소에 올립니다.
   ```bash
   git init
   git add .
   git commit -m "FLP 자산관리 앱"
   git branch -M main
   git remote add origin https://github.com/<내 계정>/flp.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
4. **Actions** 탭에서 `Deploy to GitHub Pages`가 끝나면 `https://<내 계정>.github.io/<저장소 이름>/` 에서 열립니다(대소문자까지 저장소 이름과 같아야 함). (처음에 3번 설정 전에 실행돼 실패했다면 Actions 탭에서 **Re-run**)

경로는 상대경로(`base: './'`)와 해시 라우터를 써서 저장소 이름과 상관없이 동작합니다.

## 휴대폰에서 실행

### 방법 1. 배포 주소로 설치(권장 · PC를 꺼도 됨)

위 ‘GitHub Pages 배포’를 마친 뒤 배포된 주소(HTTPS)에 휴대폰 브라우저로 접속해
- 안드로이드 Chrome: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
- iPhone Safari: 공유 → **홈 화면에 추가**

설치하면 홈 화면 아이콘으로 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다. 새 버전을 배포한 뒤에는 앱을 열 때·앱으로 돌아올 때·한 시간마다 새 버전을 확인합니다. 연 지 몇 초 안에 찾으면 바로 새 화면으로 바꾸고, 쓰는 중에 찾으면 위쪽에 **‘새 버전이 있습니다 — 새로고침’** 배너를 띄웁니다(누르면 최신 화면으로, 입력한 데이터는 그대로). Netlify·Cloudflare Pages 등 다른 정적 호스팅을 쓰려면 `npm run build`로 만든 `dist/` 폴더를 올리면 됩니다.

### 방법 2. 같은 와이파이에서 PC 개발 서버로 열기(잠깐 확인용)

```bash
npm run dev -- --host
```

터미널에 나오는 `Network: http://192.168.x.x:5173/` 주소를 휴대폰 브라우저에 입력합니다. PC와 휴대폰이 같은 와이파이에 있어야 하고, Windows 방화벽이 묻으면 ‘개인 네트워크’ 허용을 누릅니다. HTTPS가 아니어서 앱 설치·오프라인 동작은 되지 않고, PC 서버를 끄면 열리지 않습니다.

### 데이터 옮기기

데이터는 기기(브라우저)마다 따로 저장됩니다. PC에서 입력한 데이터를 휴대폰에서 쓰려면
1. PC: ‘기본 정보 → 가져오기·백업 → 전체 백업·복원 → 백업 파일 받기’로 `FLP_백업_날짜.json` 파일을 받습니다.
2. 파일을 휴대폰으로 옮깁니다(본인에게 보내는 메신저·클라우드 드라이브·USB 등). 개인 금융 정보이니 남에게 공유되는 곳에는 올리지 마세요.
3. 휴대폰: 앱을 열고 ‘기본 정보 → 가져오기·백업 → 백업에서 복원’을 눌러 그 파일을 고릅니다. 복원하면 휴대폰에 있던 데이터는 백업 내용으로 바뀝니다.

휴대폰과 PC에서 따로 고치면 서로 맞춰지지 않습니다. 한쪽을 기준으로 정해 고치고, 바꾼 뒤에는 다시 백업 → 복원으로 옮기세요. 브라우저 데이터 삭제·앱 삭제 시 데이터도 지워지니 백업 파일을 보관해 두세요.

## 주요 기능 사용법

### 부부 소득·연금
‘기본 정보 → 프로필’에서 배우자 출생연도를 넣으면 배우자 세후 소득·은퇴 나이·국민연금(개시 나이·월액)·개인연금을 **배우자 나이 기준**으로 입력할 수 있습니다. 계산할 때는 본인 나이로 바꿔, 배우자가 먼저 은퇴하면 그때부터 저축이 줄고 본인이 먼저 은퇴하면 배우자 은퇴 전까지 배우자 소득을 은퇴 후 소득으로 넣습니다. 자산의 ‘명의’(본인/배우자)는 연금 세금을 사람별로 계산할 때 씁니다.

‘개인·퇴직연금 월액’은 계좌 잔액과 별개로 정해진 금액이 나오는 연금(종신형 연금보험 등)만 넣습니다. 연금저축·IRP·퇴직연금 계좌 잔액은 자산 탭에 넣으면 인출 계획에서 꺼내 쓰므로, 같은 계좌의 월 수령액을 또 넣으면 두 번 계산됩니다. 월액이 0보다 크고 자산 탭에 연금 계좌(본인 칸은 본인·공동명의, 배우자 칸은 배우자·공동명의)가 있으면 그 칸 아래에 경고가 나옵니다.

국민연금은 생일 다음 달부터 나오므로, 본인·배우자 **출생 월**을 넣으면 개시 첫해를 그만큼만(예: 7월생 → 5개월) 계산합니다. **국민연금 연 인상률**(명목)을 넣으면 물가 대신 그 비율로 오르고, 물가보다 낮으면 실질 수령액이 해마다 조금씩 줄어듭니다.

### 그 밖의 은퇴 후 소득
프로필의 ‘그 밖의 은퇴 후 소득’에 **은퇴 뒤에** 들어오는 임대료·근로소득·사업소득 등을 시작·종료 나이, 오늘 기준 월액, 인상 주기·인상률과 함께 추가합니다(‘+ 소득 추가’를 누르면 이름 ‘기타 소득’, 종류 ‘그 밖’으로 시작). 누구 나이 기준인지(본인/배우자)도 고를 수 있습니다.

- **은퇴 전 소득**은 여기가 아니라 프로필의 ‘세후 월소득(가구)’에 합쳐 넣습니다(지금 받는 월세 포함). 종합소득세 계산용 세전 급여는 ‘은퇴 전 세전 총급여’ 칸에 따로 넣습니다.
- 종류가 **임대소득**인 항목의 이름이 자산 탭 임대용 부동산과 비슷하거나 월액이 같으면, 같은 월세를 두 번 넣었을 수 있다는 경고가 그 항목에 나옵니다.
- **국민연금·개인·퇴직연금**은 프로필의 전용 칸에 넣습니다. 임대용 부동산 월세는 ‘자산’ 탭에서 넣으면 자동 반영됩니다. 같은 돈을 여기에 또 넣으면 두 번 계산됩니다.
- **소득 종류**를 고르면 종합소득세·건강보험료 추정에 종류대로 들어갑니다. 임대소득 = 임대 필요경비율 차감(배우자 몫은 설정값), 근로소득 = 근로소득공제(한도 2,000만)·근로소득세액공제·표준세액공제 13만, 연말정산으로 낸 세금은 기납부로 빼서 5월 추가납부는 다른 소득과 합쳐 늘어난 만큼만·건보료는 총급여 × 반영률(지역가입자 50%), 사업소득 = 항목별 필요경비율 차감·건보료 100%, 공적연금(공무원·사학·군인) = 국민연금과 합쳐 연금소득공제·건보료 × 반영률, 사적연금 = 종소세 제외(1,500만 이하 분리과세)·건보료는 ‘사적연금도 반영’일 때만(켜면 급여가 있는 해에도 그 사람 소득으로 넣어, 직장가입자는 급여 외 소득 × 반영률, 피부양자 판정은 합산소득 전액, 지역가입자는 소득 × 반영률), 그 밖 = 세금 계산 제외. 임대 외에는 ‘나이 기준’으로 고른 사람의 소득으로 봅니다. 예전에 ‘임대소득’을 체크한 항목은 임대소득으로 읽습니다.

### 생활비 가정 비교
노후 진단의 ‘생활비 가정 비교’ 표에서 세 가지 가정의 성공확률·고갈 나이·월 생활비 변화를 함께 봅니다. 인출 계획 화면에는 이 카드로 가는 바로가기만 둡니다.
- **물가 연동**: 생활비가 물가만큼 올라 생활 수준을 그대로 유지
- **생활비 명목 고정**: 생활비 금액을 그대로 둠(실제 가치는 물가만큼 줄어듦)
- **연금 생활비 명목 고정(엑셀 방식)**: ‘연금계좌 인출 + 국민연금’으로 쓰는 금액을 고정. 국민연금이 나오면 그만큼 계좌 인출이 줄고, 임대료 등은 따로 모두 씀

계산에 쓸 가정은 ‘프로필 → 노후 계획 → 은퇴 후 생활비 변화’에서 고릅니다.

같은 카드의 **나이 구간별 생활비**에서 ‘70세부터 월 330만원’처럼 나이마다 월 생활비(오늘 물가 기준)를 바꿀 수 있습니다. 활동이 많은 은퇴 초기에는 더 쓰고 나이가 들수록 덜 쓰는 흐름을 반영하며, 은퇴~첫 구간 전은 은퇴 후 월 생활비를 씁니다(은퇴 나이 이전에 시작하는 구간은 은퇴부터 적용). 계산에는 기본 생활비 대비 배율로 넣어, 처방·민감도 분석에서 생활비를 바꿔 볼 때 구간도 같은 비율로 따라갑니다. 물가 연동·명목 증가율 방식과 함께 쓰며, ‘연금 생활비 명목 고정’ 방식에서는 쓰지 않습니다. 노후 진단의 월 현금흐름·가정과 인출 계획에 구간별 생활비가 반영됩니다.

### 부동산(거주용·임대용·투자용)
부동산 자산은 금융자산의 ‘용도·성격·변동성’ 대신 **부동산 용도**와 **연 시세 상승률**을 입력합니다. 부동산은 매일 사고팔 수 없어 노후 시뮬레이션의 운용자산에서 빠지므로 변동성은 쓰지 않습니다.
- **거주용**: 팔기 전까지는 순자산·부동산 편중 점검에만 들어갑니다. 시세 상승률은 장기 물가 + 0~1%p 정도(예: 2.5~3.5%)를 넣고, 매각 연도를 넣었을 때만 매각대금 계산에 씁니다. 다운사이징이면 **새 집 구입액**(오늘 시세)을 넣으면 그만큼 빼고 들어옵니다.
- **임대용**: **월세·임대보증금·계약 갱신 주기·갱신 때 인상률·공실·관리 경비율**을 넣습니다. 보증금은 돌려줄 돈이라 부채(순자산·부채비율)에 들어가고, 경비를 뺀 월세는 은퇴 후 소득으로(갱신 주기마다 인상, 매각 전 해까지) 노후 진단·인출에 반영됩니다. 은퇴 전 월세는 세후 월소득에 넣고, ‘그 밖의 은퇴 후 소득’에 같은 월세를 또 넣지 마세요.
- **주택연금**(거주용): **가입 나이**(본인 기준)를 넣으면 그 나이의 예상 시세와 부부 중 연소자 나이로 월 수령액을 자동 추정합니다(한국주택금융공사 2026.3 월지급금 예시, 일반주택·종신 정액형, 주택가격 12억까지·연령별 최대 지급액). 공사 조회 금액이 있으면 **월 수령액**(오늘 기준)에 직접 넣으세요. 정액형이라 가입 뒤 명목 금액이 평생 같고(실질로는 물가만큼 줄어듦), 노후 진단·인출의 연금 소득으로 들어갑니다. 대출 형식이라 종합소득세·건강보험료 대상이 아니며, 주택연금을 쓰면 매각 계획은 쓰지 않습니다. 부부 중 한 명이 55세 이상이어야 반영합니다. 기대수명까지 받았을 때의 대출 잔액(월지급금 + 이자 + 보증료, 기본 금리 3.8% = COFIX+0.85%p 가정 · 초기보증료 1.0% · 연보증료 0.95%이며 자산의 **대출 금리·초기보증료·연보증료** 칸에서 바꿀 수 있음)을 예상 시세에서 뺀 **상속 시 남는 주택 가치**를 자산 설명과 노후 진단 가정에 보여 줍니다(순자산·부채에는 넣지 않는 참고 값). 주택연금은 공시가격 12억원 이하 주택만 가입할 수 있어, 지금 시세가 약 17억(공시가격이 시세의 70% 안팎이라고 본 어림)을 넘으면 자산 탭에 ‘가입이 어려울 수 있어요’ 경고가 나오고, 노후 진단 가정표(‘주택연금 가입 요건 주의’)와 이정표의 주택연금 가입 항목에도 공시가격을 확인하라는 문구가 붙습니다. 계산은 가입된다고 가정한 값이라, 가입이 안 되면 노후 진단 결과가 주택연금 소득만큼 좋게 나옵니다. 넘는다면 가입 나이를 0으로 두거나 더 작은 집으로 옮긴 뒤 가입하는 계획으로 바꾸세요.
- **투자·기타**(토지·분양권 등): 매각 연도에 시세차익을 실현하는 자산으로 봅니다.
- **명의**: 본인·배우자·**공동명의(본인 지분 %)**. 임대용 부동산 월세의 종합소득세·건강보험료를 지분대로 나눠 계산합니다.
- **매각 연도·매각 비용률**: 매각 연도의 예상 시세 − 매각 비용(양도세·중개보수 실효율, 1주택 비과세면 0.5% 안팎) − 보증금 반환 − 새 집 구입액이 그해 금융자산(ISA·일반계좌)으로 들어와 함께 운용됩니다. 0이면 계속 보유합니다.
- 홈 ‘용도별’ 자산 구성에는 부동산이 용도별로 따로 나오고, 투자 점검의 용도별 배치·처방의 목적별 바구니·목적자금 배정은 금융자산만으로 계산합니다.

### 수령 시점이 정해진 자산(노란우산 등)
자산의 ‘명의·수령 시점’ 설정에서 **수령 연도**와 **수령 시 세율**을 넣으면 그 전까지는 인출 계산에서 빠지고 기대수익률로 불어난 뒤, 수령 연도에 세후 일시금으로 들어와 다른 금융자산과 함께 운용됩니다.

### 연금 세금 점검
연금계좌 자산마다 **과세제외**(세액공제 안 받은 원금), **퇴직금 재원**, **연금수령 1년차 연도**를 넣고, 프로필 ‘연금 세금’에 퇴직소득세 실효세율, 퇴직금 연금 실수령 1년차, **퇴직금 계좌 매년 최소 인출**(연 금액, 예: 12만원)을 넣습니다. 인출 계획의 ‘연금 세금 점검’ 카드가 보여 주는 것:
- 첫해 세전 인출·세금, 계획 기간 세금 합계, 세금을 반영한 자산 고갈 나이
- 1인 연 1,500만원(세전, 명목) 분리과세 한도를 넘는 해
- **계좌별 인출 지시**: 계좌마다 연금수령연차, 증권사 정기지급(연금 지급신청)으로 걸 월 세전 금액, 예상 세금, 세후 수령액, 올해 계획, 연금수령한도와 한도 사용률. 한도를 넘는 계좌는 경고. 만 55세가 되는 해에 여는 계좌의 월액은 생일이 든 달부터 12월까지로 나눔

한 계좌 안에서는 법정 순서(과세제외 → 퇴직금 재원 → 과세재원)로만 빠지므로, 퇴직금이 들어 있는 계좌의 과세재원(운용수익 포함)은 퇴직금 재원을 다 쓴 뒤에야 꺼낼 수 있습니다. 운용수익은 모두 과세재원으로 쌓이고 과세제외·퇴직금 재원은 처음 금액 그대로입니다. 퇴직소득세 감면이 30%에서 40%로 커지는 실수령 11년차는 퇴직금 계좌에서 **실제로 꺼낸 해만** 세므로, ‘매년 최소 인출’을 넣어 두면 쓸 일이 없는 해에도 그 금액을 꺼내(세후 금액은 ISA·일반계좌로) 연차가 끊기지 않습니다.
연도별 인출 스케줄에는 세금·세전 인출·한도 사용액 열이 추가되고, 한도를 넘는 해는 노란색으로 표시됩니다.

연금 자산마다 넣을 수 있는 인출 설정:
- **인출 시작 연도**: 그 전에는 꺼내지 않습니다(추가 납입을 받는 계좌로 남겨 둘 때). 연금수령연차는 ‘연금수령 1년차 연도’부터 그대로 셉니다.
- **꺼내는 순서**: 같은 사람 계좌 중 작은 번호부터 꺼냅니다(예: 연금저축 먼저 1, IRP 2).
- **같은 계좌**: 한 계좌를 투자형·안전형 두 줄로 나눠 적을 때 두 줄에 같은 이름을 넣으면 연금 세금·수령한도·인출 순서·이정표·인출 기록을 계좌 하나로 계산합니다(리밸런싱 ‘자산 탭에 반영’이 자동으로 넣음). 비우면 그 줄이 한 계좌입니다. 같은 계좌로 묶인 줄이 둘 이상이면 그 아래 **한 줄로 합치기** 버튼이 나와, 누르면(한 번 확인) 처음 줄 하나로 합칩니다: 금액·과세제외·퇴직금 재원은 합계, 기대수익률·변동성은 금액가중 평균, 성격은 금액이 많은 쪽, 꺼내는 순서·비교 순서는 0보다 큰 가장 작은 값, 이름은 계좌 이름이고 같은 계좌 칸은 비웁니다. 버튼 옆과 확인창에 합친 결과(금액·성격·기대수익률·변동성·과세제외·퇴직금 재원)를 미리 보여 줍니다.
- **비교 기준 순서**: 인출 계획의 ‘인출 순서·추가 납입 비교’ ① 조합에서만 쓰는 순서입니다. 모두 0이면 ①은 자산 목록 순서를 씁니다.

### 1,500만 한도 꽉 채우기
‘프로필 → 연금 세금’에서 ‘1,500만 한도 매년 꽉 채우기’를 ‘예’로 고르면, 시작 연도부터 생활비보다 많더라도 해마다 1인 1,500만원까지 과세재원을 낮은 세율(5.5~3.3%)로 미리 꺼내 세후 금액을 ISA·일반계좌에 다시 넣습니다. 인출 스케줄의 ‘ISA 재투자’ 열에 재투자액·납입액·연말 잔액이 나옵니다.

### 연금계좌 추가 납입(세액공제)
‘프로필 → 연금계좌 추가 납입’에 본인·배우자 연 납입액과 기간을 넣습니다. 납입금은 ISA·일반계좌에서 먼저 내고(모자라면 연금계좌에서 더 꺼냄), 본인 납입은 인출 시작 전 본인 계좌로 들어갑니다. 세액공제는 1인 연 900만원까지 × 공제율(종합소득금액 4,500만원 이하 16.5%, 초과 13.2%, 직접 입력 가능)이고, 종합소득세 추정을 켜면 그해 종합소득세까지만 공제합니다. 환급금은 다음 해 들어와 노후 진단·인출에 반영되고, 공제받지 못한 납입액은 과세제외 금액이 됩니다.

### 인출 순서·추가 납입 비교
인출 계획의 ‘인출 순서·추가 납입 비교’ 카드에서 다섯 가지 조합을 나란히 봅니다. 인출 시작 연도를 늦춘 계좌에 과세재원이 묶여 그 해 1,500만 한도를 다 못 쓴 조합이 있으면 ‘한도 미사용’ 열이 나옵니다. ① 계좌별 비교 기준 순서(없으면 자산 목록 순서)로 모든 연금계좌를 바로 인출 · 납입 없음, ② 계좌별 꺼내는 순서·인출 시작 연도 적용 · 납입 없음, ③ ② + 본인 추가 납입, ④ ② + 본인·배우자 추가 납입, ⑤ ② + 배우자 추가 납입만. 조합마다 세금 합계, 세액공제 환급, 순 세금, 1,500만 한도를 넘는 연도와 16.5%로 꺼낸 금액, 연금수령한도 초과 계좌, 세금을 반영한 고갈 나이를 계산합니다. 계획이 90세를 넘으면 90세까지 세금 합계와 90세 연말 잔액(세금 반영, 오늘 물가)도 보여 줘서, 모든 조합이 마지막 해에 바닥나도 차이를 비교할 수 있습니다. 카드 위 납입액·기간은 비교에만 쓰이고, 계획에 넣으려면 ‘프로필 → 연금계좌 추가 납입’에 입력합니다.

### 종합소득세·건강보험료
‘그 밖의 은퇴 후 소득’에서 임대료 항목의 **임대소득**을 체크하고, ‘프로필 → 종합소득세·건강보험료’를 ‘추정하기’로 바꾼 뒤 임대소득 배우자 몫·필요경비율, 국민연금 과세대상 비율, 소득공제, 현재 월 건강보험료(고지서)를 넣습니다. 아직 일하고 있으면 ‘프로필 → 부부 소득·연금’의 **은퇴 전 세전 총급여(연, 오늘 기준)**를 본인·배우자 각각 넣습니다. 각자 은퇴 전 해까지 이 급여를 근로소득으로 월세 등 다른 소득과 합쳐 세율 구간·근로소득세액공제·표준세액공제를 계산하고, 회사 연말정산으로 낸 세금(급여만 있다고 본 결정세액)은 기납부로 빼서 5월 추가납부에는 월세 등 때문에 늘어난 세금만 들어갑니다. 급여에 붙는 건보료는 직장에서 낸다고 보고 넣지 않고, 저축·노후 계산에는 쓰지 않습니다(그쪽은 세후 월소득). **급여가 있는 사람은 그 해 직장가입자**로 봅니다: 재산분이 없고, 급여 외 소득(임대·사업소득 + 공적연금·근로소득 × 반영률)이 연 2,000만원을 넘는 부분에만 소득월액 보험료가 붙습니다(표의 월 건보료에 ‘직장’ 표시). **부부 중 한 명만 일하는 해**에는 다른 한 명이 피부양자 요건(임대·사업소득 없음, 연금 등 합산소득 2,000만원 이하, ‘부동산 자산으로 추정’일 때 본인 명의 재산 과표 5.4억 이하 — 소득 1,000만원 이하면 9억 이하)을 채우면 보험료가 없고(‘직장+피부양’), 못 채우면 그 사람만 지역가입자로 본인 소득과 본인 명의(공동명의는 지분) 재산분을 냅니다(‘직장+지역’). 이런 해는 표의 월 건보료 아래에 누가 왜 빠졌는지(예: ‘배우자: 합산소득 3,377만원(사적연금 3,377만원 포함)이 2,000만원 초과’)를 보여 줍니다. 임대·사업소득이 조금이라도 있으면 사업자등록이 있다고 보고 피부양자에서 뺍니다(보수적). 사업자등록이 없다면 **‘피부양자 판정: 사업자등록 없음’**을 ‘예’로 바꾸세요(부부이고 은퇴 전 급여를 넣었을 때 보임): 임대 외 사업소득금액이 연 500만원 이하면 피부양자로 인정합니다. 임대소득은 있으면 항상 빠집니다(주택임대는 등록과 상관없이 탈락, 상가 임대는 사업자등록이 필수). 고지서 역산 방식에서는 ‘직장+지역’인 해에 세대 재산분을 그 사람 명의(공동명의는 지분) 부동산이 세대 부동산 시세에서 차지하는 비율만큼만 넣고(첫해 고지서가 그 사람 몫이면 같은 비율로 나눠 세대 재산분을 되돌려 은퇴 후에 씀, 부동산 자산이 없으면 전체, 재산등급이 계단식이라 어림값), 부부 모두 직장·피부양자인 동안에는 ‘현재 월 건강보험료’ 칸에 은퇴 후 예상 지역 보험료를 넣어야 은퇴 후 재산분이 계산됩니다(모르면 ‘부동산 자산으로 추정’ 권장). 둘 다 은퇴한 해부터는 부부 한 세대 지역가입자입니다. **건보료 재산분**을 ‘부동산 자산으로 추정’으로 바꾸면 고지서 대신 부동산 자산의 해마다 오르는 시세 × 시세 대비 공시가격 비율(기본 69%) × 공정시장가액비율(주택 60%)로 세대 재산 과세표준을 구하고, 기본공제 1억을 뺀 금액의 재산등급 점수(시행령 별표4) × 211.5원(2026년)으로 연도별 재산분을 추정합니다. 부부 한 세대 합산이라 명의·지분과 상관없고, 매각 연도부터는 빠지며(주택연금 주택은 계속 포함), 임대보증금은 집주인 재산에서 빼지 않습니다(세입자의 전월세 재산으로 잡힘). **주택 구입 대출 공제**를 ‘예’로 하면 부채 탭에서 ‘실거주 주택 구입 대출’로 표시한 대출의 해마다 줄어드는 잔액(원리금 균등 상환) × 60%를 5,000만 한도로 재산 과세표준에서 빼고, 그 해 주택(거주용·임대용)이 2채 이상이면 빼지 않습니다(실제로는 공시가격 5억 이하 주택을 취득 전후 3개월 안에 빌린 대출이어야 하고 공단에 신청해야 함). 대출 표시는 1세대 1주택으로 지금 사는 집을 사려고 받은 대출(주택담보대출·보금자리론 등)에만 하고, 전세자금대출·신용대출·투자용 주택 대출은 표시하지 않습니다. 표시했는데 ‘추정하기’·‘부동산 자산으로 추정’·‘주택 구입 대출 공제’ 중 꺼진 것이 있으면 부채 카드에 무엇을 바꿔야 반영되는지 안내합니다. 프로필의 ‘주택 구입 대출 공제’ 항목 아래에는 표시한 대출 이름·잔액과 올해 공제액(잔액 × 60%, 한도 5,000만, 2주택이면 0)이 나옵니다. 인출 계획의 ‘종합소득세·건강보험료’ 표 ‘대출 공제’ 열에는 해마다 빠지는 공제액이 나오고, 공제가 처음 0이 되는 해(상환 끝 또는 2주택)는 ‘0 (공제 끝)’으로 강조하고 표 아래에 그 해를 적습니다. 자동차와 전월세 임차 대출은 넣지 않습니다. 인출 계획의 ‘종합소득세·건강보험료’ 카드에 연도별 종합소득세(본인/배우자)·5월 추가 납부·월 건보료·연 부담과, 첫해보다 늘어나는 금액 중 국민연금 몫이 나옵니다. 은퇴 전 급여를 넣었다면 ‘기준 해 대비’로 바뀌어, 급여가 있는 해는 첫해와, 급여가 모두 끝난 해(은퇴 후 첫해)부터는 그 해와 비교합니다(급여가 빠져 세금이 줄어든 것을 감소로 보이지 않게). ‘늘어난 세금 인출에 더하기’를 고르면 국민연금 몫만큼 해마다 자산에서 더 꺼내는 것으로 노후 진단·인출을 다시 계산합니다.

### 가드레일 비교와 연말결산
인출 계획에서 가드레일 폭·조정 폭·‘감액만’을 바꾸며 정액 인출과 자산 유지 확률·고갈 나이를 비교합니다. 계획을 정하면 연말결산 카드의 ‘지금 계획을 기준선으로 고정’을 누르고, 해마다 12월 말 실제 금융자산(수령 전 노란우산 등은 빼고)과 그해 인출액을 ‘연말결산’에 기록하면 기준선과 비교해 다음 해 권장 인출액을 알려 줍니다. 표의 **실제 수익률(추정)** = 12월 말 자산 ÷ (연초 자산 − 그 해 인출) − 1이며, 연초 자산은 직전 해 결산값(첫해는 기준선을 고정할 때의 자산)입니다.
- **필요 자산으로 감액 판정**: 가드레일의 기준선은 평균 수익으로 정액 인출할 때의 연초 자산이라, 몇 년 뒤 매각대금·일시금이 크게 들어오는 계획에서는 기준선이 실제로 끝까지 버티는 데 필요한 자산보다 훨씬 높아집니다. 그대로 비교하면 자산이 충분한데도 기준선보다 낮다는 이유로 인출을 줄이게 되므로, 감액 판정은 기준선과 **필요 자산**(평균 수익이 날 때 그 해 초 자산이 얼마면 끝까지 계획 인출을 댈 수 있는지, 뒤에 들어올 돈은 들어오는 해부터 빼되 그 전 해 인출은 그대로 필요) 중 낮은 쪽으로 합니다. 줄였던 인출은 그 낮은 선의 상단선(+15%)만 넘어도 계획 금액까지 되돌리고, 계획보다 늘리는 판정은 기준선 그대로입니다. 필요 자산은 ‘기준선으로 고정’할 때 연말결산 기준선에도 함께 저장되며, 예전에 고정한 기준선에는 없어 기준선만으로 판정하므로 ‘기준선 다시 고정’을 눌러야 적용됩니다.
- **계좌별로 입력 → 다음 해 계획에 이어받기**: ‘12월 말 금융자산’ 아래 ‘계좌별로 입력(다음 해 계획에 이어받기)’을 누르면 그 해 12월 말에 꺼낼 수 있는 금융자산(부동산·수령 전 노란우산 등 제외)마다 평가액 칸이 나오고, 합계가 결산 금액이 됩니다(처음 값은 자산 탭의 지금 금액). 저장하면 ‘이어받기’ 상자가 생기고, ‘바뀔 내용 보기’에서 계좌별로 자산 탭 금액·과세제외 금액·퇴직금 재원이 어떻게 바뀌는지 확인한 뒤 ‘자산 탭에 적용’을 누릅니다. 자산 금액은 12월 말 평가액으로 바뀌어 다음 해 계획의 시작 자산이 되고, 연금계좌는 그 해 월별 실제 인출 기록 합계만큼 법정 인출 순서(과세제외 → 퇴직금 재원)대로 두 재원이 줄어듭니다(새 잔액을 넘지 않게 맞춤). 두 금액을 이미 직접 고쳤다면 체크를 끄고 금액만 넘기세요. 재원은 한 결산에서 한 번만 줄이고, 다시 적용하면 금액만 넘깁니다. 잘못 눌렀다면 **‘이어받기 되돌리기’**로 적용 직전의 자산 금액·과세제외 금액·퇴직금 재원으로 돌아갑니다(적용할 때 직전 값을 결산 기록에 저장해 둠, 여러 번 적용했으면 처음 적용하기 전 값으로). 되돌리면 그 뒤 자산 탭에서 직접 고친 세 값도 적용 전으로 돌아가고, 재원 줄이기도 다시 할 수 있게 됩니다. 적용 뒤 지운 계좌는 건너뜁니다. 연금수령연차는 연도로 계산하므로 따로 넘길 것이 없습니다.

### 월별 실제 인출 기록
인출 계획의 ‘월별 실제 인출 기록 — 계획 대비’ 카드(이미 인출 중이거나 기록이 있을 때 표시)에서 달마다 계좌에서 실제로 지급된 **세전 금액(만원)**을 적습니다. 열은 ‘계좌별 인출 지시’의 연금계좌와 **ISA·일반**(연금계좌 밖에서 생활비로 꺼낸 돈)이고, 빈칸의 흐린 숫자가 그 달 계획(그 해 계획 ÷ 계획 개월 수, 첫해는 이번 달부터 12월까지)입니다. ‘계획대로’를 누르면 그 달 빈칸을 계획 금액으로 채우고, 칸을 비우면 기록이 지워집니다.
- 위쪽 요약: 그 해 계획(세전) · 지금까지 계획(지난 달 수만큼) · 실제 인출 누적 · 계획 대비 차이.
- 표 아래: 계좌별 **연 누적 실제 · 올해 계획 · 연금수령한도 · 한도 사용률**. 연 누적이 연금수령한도(연초 평가액 ÷ (11 − 연금수령연차) × 120%)를 넘으면 빨갛게 표시하고, 아직 연금수령을 할 수 없는 계좌에서 꺼낸 돈은 전액 한도 밖으로 봅니다.
- 계획은 지금 자산·설정으로 다시 계산한 값입니다. 계좌 이름을 바꾸면 예전 이름으로 적은 기록은 ‘지금 계획에 없는 계좌’ 열로 따로 남습니다.
- **CSV**: 열은 `월, 계좌, 세전 인출액, 메모`(월은 2026-11·2026/11·2026.11.03 모두 읽음). 가져오면 같은 달·계좌는 덮어쓰고, 파일 안에 같은 달·계좌가 여러 줄이면 더합니다. 전체 백업(JSON)에도 들어갑니다.
- 연말결산의 ‘그 해 실제 인출’ 칸 아래 ‘월별 기록 합계 넣기’를 누르면 그 해 합계가 들어갑니다.

### 수익률 시나리오별 잔액과 목돈 지출 민감도
인출 계획의 같은 이름 카드는 은퇴 후 수익률이 **비관·기본·낙관**(기본 = 지금 설정, 비관·낙관은 기본 ∓2%p에서 시작해 직접 수정)으로 해마다 그 값만 났을 때의 80·90·100세(계획 기간 안의 나이만)와 마지막 해 연말 잔액, 자산이 바닥나는 나이, 연금 세금 합계를 보여 줍니다. 고른 인출 전략·인출 시작 자산 그대로이고 연금계좌가 있으면 세전 인출(연금 세금)을 반영한 잔액이라, 기본 행은 ‘연금 세금 점검’의 ‘세금 반영 시 자산 고갈’과 같습니다.
그 아래 **목돈 지출 민감도**는 고른 시나리오(기본은 비관)에서 세로 월 생활비(인출액 고정 방식이면 월 고정 인출액, 노후 진단 민감도와 같은 간격) × 가로 목표 탭 지출(목적자금·반복 지출)을 0~150%로 바꿨을 때 자산이 바닥나는 나이입니다. ‘바꿀 첫 해’ 전의 지출과 만기일시 대출 원금·보험료·세금은 그대로 둡니다. 표 아래에 목돈을 그대로 둘 때 유지되는 가장 큰 생활비와, 생활비를 그대로 둘 때 유지되는 가장 큰 목돈 비율을 알려 줍니다.

### 자산 배치 가이드와 이정표
인출 계획의 ‘인출용 자산 배치 가이드’는 전체 기준 바구니(현금성 2년 · 채권·배당 3~5년차 · 대체 · 성장)와 함께, 연금 세금 계산의 계좌별 인출 계획으로 **계좌마다** 바구니 목표를 보여 줍니다(인출이 나가는 그 계좌 안에 현금성을 둠). 이름에 IRP·DC·퇴직이 들어간 계좌는 위험자산(성장 + 대체)을 평가액의 70%까지만 잡습니다. 대체자산 목표 비중과 ‘주식형 지수 고점 대비 등락률’을 넣으면 지금 적용할 규칙(고점 부근 · 보통 · −15% 이하 하락장)을 알려 줍니다.

‘다가오는 이정표·할 일’ 카드는 프로필·자산·부채·목표에 넣은 값으로 일정표를 만듭니다: 연금수령 11년차(수령한도 없음), 만 55세 연금 개시, 계좌별 인출 시작 연도(만 55세가 되는 해면 생일이 든 달), 노란우산 등 일시금 수령, 국민연금 개시(생일 다음 달), 퇴직금 실수령 11년차(감면 40%), 70·80세 연금소득세율, 추가 납입과 세액공제 환급, 부동산 매각·주택연금, 만기일시 대출, 한 번 쓰는 목표. 위쪽에는 올해·내년에 챙길 일(연금 개시 신청, 12월 전 추가 납입, 5월 환급 확인, 퇴직금 계좌 최소 인출, 1월 연말결산)을 따로 모아 보여 줍니다.

### 백업과 복원
‘기본 정보 → 가져오기·백업’에서
- **전체 백업·복원(JSON)**: ‘백업 파일 받기’ / ‘백업에서 복원’. 프로필·자산·목표·연말결산·월별 실제 인출 기록 등 모든 데이터를 파일 하나로 저장하고 되살립니다. 기기를 옮기거나 브라우저 데이터를 지우기 전에 꼭 받아 두세요.
- **CSV 가져오기/내보내기**: 표 하나씩(자산·부채 등) 엑셀로 편집할 때 씁니다. 자산 CSV에는 기본 열 뒤에 **명의·수령·매각 연도·수령 세율·매각 비용률**과 부동산 전용 열(용도·본인 지분·월세·임대보증금·갱신 주기·인상률·경비율·새 집 구입액·주택연금 가입 나이·월 수령액·대출 금리·초기보증료·연보증료), 연금 계좌 전용 열(과세제외 금액·퇴직금 재원·연금수령 1년차 연도·인출 시작 연도·꺼내는 순서·비교 기준 순서·같은 계좌)이 선택 항목으로 붙고, 해당 유형이 아닌 행의 전용 열은 빈칸입니다. 부채 CSV에는 선택 열 **상환 방식**(‘만기일시’·‘원금균등’ 또는 빈칸 = 원리금균등)과 **건보 대출 공제**(‘주택 구입’ 또는 빈칸)가 붙습니다. 보험 CSV에는 **납입 종료 나이** 열과 선택 열 **피보험자**(‘본인’·‘배우자’·‘자녀’ 또는 빈칸 = 본인)·**자녀 출생연도**가 있으며, 납입 종료 나이 열이 없는 예전 파일은 0(계속 납입)으로 읽습니다. 양식 파일을 받아 채운 뒤 ‘기존 데이터에 추가’ 또는 ‘기존 데이터를 지우고 교체’를 골라 가져옵니다. 읽을 수 있는 행이 하나도 없는 파일(대상이 다른 표, 빈 파일)은 ‘교체’를 골라도 기존 데이터를 지우지 않습니다.

## 계산 방식 요약

- **목표 현가화**: 현재가치 금액 × (1+비용상승률)^년수 = 미래 필요액 → ‘중기·목적자금’ 자산을 시기가 빠른 목표부터 배정 → 부족분을 월 적립액(PMT)으로 산출. 매년 반복 지출은 시작 나이(이미 시작했으면 지금)에 남은 해의 지출을 모두 낼 금액(같은 기대수익률로 굴리며 해마다 초에 꺼내 씀)을 미래 필요액으로 보고, 중기 자산은 일시 목표에 먼저 배정한 뒤 남는 금액을 배정
- **몬테카를로**: 연 수익률 ~ 정규분포(금액가중 기대수익률, 변동성), 물가를 뺀 실질 기준, 시드 고정으로 재현 가능. 은퇴 전에는 한 해 굴린 뒤 연말에 저축을 더하고, 은퇴 후에는 그 해 쓸 돈을 연초에 먼저 꺼낸 뒤 남은 돈만 굴림(인출 계획의 정액 인출과 같은 순서라 두 화면의 평균 수익 경로·고갈 나이가 같고, 연말에 꺼내는 것보다 보수적). 은퇴 전 저축 적립, 목표 시점 목적자금 지출, 은퇴 후 (생활비 − 연금 + 남은 대출 상환) 인출. 부동산은 거주용으로 보고 제외
- **하락장 가드레일 비교**: 노후 진단에서 지금 방식(생활비 그대로)과 하락장 가드레일 방식의 성공확률·고갈 나이 중앙값을 나란히 보여 줌. 하락장은 시장 지수(명목 누적수익률, 인출과 무관)가 그때까지의 최고점보다 ‘하락장 기준’(기본 20%) 이상 낮은 해이고, 은퇴 후 그런 해에는 생활비(인출액 고정 방식이면 고정액)를 ‘하락장 생활비 감축’(기본 10%)만큼 줄임. 대출 상환·목표 탭 지출·보험료는 줄이지 않음. 두 방식은 같은 시드로 같은 시장 경로를 지나 차이는 가드레일 효과만 남음. 기준은 점검 기준 탭에서 바꾸고 감축을 0으로 두면 비교하지 않음. 성공확률·처방·민감도는 지금 방식 기준. 같은 카드의 ‘강도별 성공확률’ 표는 하락장 기준(10·15·20·30%) × 생활비 감축(5·10·20%) 조합의 성공확률과 지금 방식 대비 차이(%p)를 보여 주고(지금 설정 칸은 테두리, 한 줄씩 나눠 계산), 생애 자산 잔액 곡선에는 지금 설정 가드레일 방식의 중앙값 선을 겹쳐 그림. 생활비를 줄인 해를 은퇴 나이부터 5세 구간별 시나리오 평균 연수 막대그래프로 보여 주고 은퇴 후 첫 10년에 몰린 비율과 가장 많은 구간을 알려 줌(자산이 바닥난 뒤의 해는 세지 않음). 같은 입력·설정의 결과는 한 번만 계산해 카드·표·곡선이 함께 씀
- **스트레스 테스트**: 노후 진단에서 지금 계획에 나쁜 일 하나를 더했을 때의 성공확률·지금 계획 대비 차이(%p)·평균 수익 가정 고갈 나이·마지막 해 잔액 중앙값을 표로 보여 주고, 가장 약한 상황과 목표 확률에 못 미치는 상황을 알려 줌. 상황은 은퇴 직후 폭락(인출 시작 해 수익률 −30%), 수익 없는 10년(인출 시작부터 10년 수익률 = 물가), 고물가(물가 +2%p, 수익률 그대로), 장수(기대수명 +5세), 국민연금 삭감(부부 국민연금 −20%, 국민연금을 넣었을 때), 저축 중단(은퇴 전이고 저축 여력이 있을 때, 대출 상환이 끝나 늘어나는 저축도 없음), 폭락 + 고물가. 기본 계산과 같은 시드·횟수라 같은 시장 경로를 지나고, 폭락·수익 없는 해는 그 해 수익률만 바꿈. 고물가는 목표 탭 지출·매각대금 등 미리 환산한 금액을 그대로 둔 어림값, 장수는 기간만 늘림
- **배우자 사별 분석**: 노후 진단의 같은 이름 카드(배우자 출생연도를 넣었을 때 표시). 본인 또는 배우자가 본인 나이 65·75·85세에 먼저 떠나는 경우마다 성공확률·지금 계획 대비 차이·사별 다음 해 연금·소득(월)·평균 수익일 때 고갈 나이를 보여 줍니다. 혼자일 때 생활비는 부부 생활비의 70%(바꿀 수 있음, 인출액 고정 방식은 반영 안 됨), 떠난 사람의 국민연금은 끊기고 유족연금(떠난 사람 연금액 × 지급률 40·50·60%)이 나오며, 남은 사람이 자기 노령연금을 받으면 ‘노령연금 + 유족연금의 30%’와 ‘유족연금만’ 중 큰 쪽으로 계산합니다. 떠난 사람의 개인·퇴직연금 월액과 근로소득은 끊기고, 보험 탭의 사망보장은 그 해 금융자산으로 들어옵니다. 본인이 먼저 떠나면 배우자 기대수명까지 계산합니다. 상속세·건강보험료 변화·유족연금 나이 요건은 넣지 않은 어림값입니다
- **은퇴 후 자산 운용**: 프로필에서 ‘따로 입력’을 고르면 은퇴 나이부터 따로 입력한 기대수익률·변동성을 노후 진단·인출 계획에 적용. 변동성 칸에는 수익률에 맞는 권장 범위(예금 금리 약 3%를 넘는 초과수익 1%마다 2.5~5%: 4% → 2.5~5%, 6% → 7.5~15%, 8% → 12.5~25%)가 나오고, 범위보다 낮으면 성공확률이 낙관적으로 나온다는 경고, 높으면 보수적이라는 안내가 나옴. 경고 옆 ‘권장값으로 맞추기’를 누르면 은퇴 후 변동성을 권장 범위의 가운데 값(0.5% 단위)으로 바꿈
- **대출 상환 종료**: 상환 종료 나이(비우면 잔액·금리·월상환액으로 원리금 균등 상환 기간 계산)가 은퇴 전이면 그 뒤로 월 상환액만큼 저축이 늘고, 은퇴 후까지 이어지면 남은 기간 동안 인출액에 더함(상환액은 현재 금액 그대로 가정)
- **대출 연도별 상환**: 노후 진단 화면에 대출별 연 상환액·연말 잔액 표(상환 방식·금리 표시, 은퇴 나이 행 강조)가 나옵니다. 지금 월 상환액·잔액·금리로 추정한 물가 반영 전 금액이며, 원금균등은 해마다 줄고 만기일시는 만기 나이에 ‘원금 일시 상환’으로 표시합니다. 끝나지 않는 대출은 기대수명까지 보여 줍니다
- **원금균등 상환**: 부채의 상환 방식을 ‘원금균등 상환’으로 바꾸고 월 상환액에 이번 달 낸 금액(원금 + 이자)을 넣습니다. 월 원금 = 상환 종료 나이가 있으면 잔액 ÷ 남은 개월, 없으면 월 상환액 − 이번 달 이자이고, 잔액은 해마다 월 원금 × 12만큼 줄어 잔액 ÷ 월 원금 개월 뒤 끝납니다. 이자가 줄어 월 상환액이 해마다 월 원금 × 12 × 월 금리만큼 줄고, 은퇴 전에는 줄어든 만큼 저축이 늘며 은퇴 후에도 남으면 그 해 상환액을 자산에서 인출합니다
- **만기일시 상환**: 부채의 상환 방식을 ‘만기일시 상환’으로 바꾸면 월 상환액(이자)은 만기 전 해까지 내고, 상환 종료 나이(만기)에 남은 원금을 자산에서 한 번에 갚습니다. 원금은 명목 금액이 그대로라 실질 금액 = 원금 ÷ (1 + 물가)^(만기까지 햇수)로 빠지며, 만기 나이가 없으면 원금 상환을 반영하지 않습니다(부채 카드 테두리와 안내 문구를 경고색으로 표시하고 문구를 누르면 상환 종료 나이 입력칸으로 이동, 홈 주요 점검 사항 맨 앞·투자 점검 위험요인 체크리스트·처방전에 ‘만기 나이 입력 필요’ 경고, 재무점수에는 넣지 않음). 처방전에는 만기 원금이 평균 수익 가정에서 그 해 초 금융자산의 몇 %인지와 상환 뒤 잔액이 나오며(상환 뒤 0이면 위험, 50% 초과면 주의), 인출 계획의 연도별 스케줄에는 그 해 필요 지출 아래 ‘대출 원금 상환’으로 따로 표시합니다
- **이미 은퇴한 경우**: 현재 나이가 은퇴 나이 이상이면 저축 없이 지금 금융자산에서 바로 인출을 시작(필요자금·인출률·인출 계획 모두 현재 나이 기준)
- **올해는 남은 달만**: 계산은 달력 연도 단위(나이 = 연도 − 출생연도)이고, 지금 자산에는 올해 지난 달의 지출·저축이 이미 반영돼 있으므로 첫해는 이번 달부터 12월까지만 셉니다(11월이면 2개월). 그 기간만큼 생활비·소득·저축·대출 상환·해마다 나가는 지출(반복 지출·보험료)·수익을 계산하고, 일시금·한 번 쓰는 목표는 그대로 넣습니다. 인출률과 월 금액은 연으로 환산한 값이라 달에 따라 바뀌지 않습니다. 1월에는 1년 전체입니다. 인출 계획 스케줄 첫 행에 ‘2개월’처럼 표시하고, 계좌별 정기지급 월액도 남은 달로 나눕니다. 연말결산 기준선을 고정하면 첫 구간(고정한 달~12월)과 그 뒤 1년 단위가 그대로 저장됩니다
- **은퇴 후 소득**: 국민연금·배우자 국민연금(배우자 나이를 본인 나이로 환산)·개인연금은 실질 금액 일정(국민연금 연 인상률을 넣으면 명목 그 비율로 오르고 물가로 할인, 출생 월을 넣으면 첫해는 생일 다음 달부터 월할). 임대료 등은 오늘 기준 월액에 ‘인상 주기마다 인상률’을 적용하고 물가로 할인
- **월 저축 여력** = 세후 소득 − 지출(고정·변동) − 대출 월 상환액 − 보험 탭 월 보험료 합계. 마이너스면 은퇴 전에도 그 부족분을 해마다 금융자산에서 꺼내는 것으로 계산하고(0으로 자르지 않음), 홈 화면에 안내가 나옵니다. 연금 계좌·투자 자산에서 꺼내 쓰는 돈은 세후 소득에 넣지 않습니다. 은퇴 나이가 지나면 홈의 월 현금흐름은 노후 진단과 같은 방식(은퇴 후 월 생활비 + 대출 − 연금·소득 = 금융자산에서 인출, 인출률·상한)으로 바뀌고, 지출 탭과 세후 월소득은 쓰지 않습니다. 지출 항목 이름·분류에 ‘보험’이 들어간 항목이 있으면 보험료가 이미 들어 있다고 보고 보험 탭 금액은 더하지 않으며, 지출 화면에 중복 의심 안내가 나옵니다. 보험마다 **피보험자**(본인·배우자·자녀)를 고르고 **납입 종료 나이**를 그 사람 나이로 넣습니다. 배우자는 기본 정보의 배우자 출생연도, 자녀는 보험에 넣은 자녀 출생연도로 본인 나이로 바꿔 계산하며(출생연도가 없으면 본인 나이로 봄), 보험 카드 아래에 ‘배우자 60세 = 본인 62세’처럼 함께 보여 줍니다. 납입 종료 나이를 넣으면 그 나이부터 보험료가 지출에서 빠지고, 은퇴 전에 끝나면 그 나이부터 월 보험료만큼 은퇴 전 저축이 늘어나는 것으로 계산하며 처방전에 ‘보험 납입 완료 후 저축 증가’가 나옵니다. 납입 종료 나이가 은퇴 나이보다 늦으면 은퇴(이미 은퇴했으면 지금)부터 종료 전 해까지 보험료를 매년 자산에서 꺼내는 것으로 계산하며(명목 고정이라 실질 = 연 보험료 ÷ (1 + 물가)^햇수), 노후 진단의 월 현금흐름·가정과 인출 계획 스케줄에 ‘보험료’로 표시합니다. 0이면 계속 납입하는 것으로 보고 은퇴 후에도 기대수명까지 보험료를 매년 자산에서 꺼내는 것으로 계산합니다(은퇴 후 생활비에 이미 넣었다면 생활비에서 빼야 이중으로 잡히지 않음). 지출에 보험료 항목이 따로 있으면 이 두 가지를 반영하지 않으며, 지출 화면의 중복 경고에서 ‘지출에서 이 항목 지우기’를 누르면 그 항목을 지우고 보험 탭 금액이 자동으로 더해집니다. 노후 진단의 월 현금흐름 카드 아래 **은퇴 전 저축 변화**에 보험 납입 완료(‘자녀 실손 납입 완료 (자녀 20세 · 본인 50세)’)·배우자 은퇴·대출 상환 완료로 저축이 바뀌는 나이와 월 금액을 보여 줍니다
- **반복 지출**: 재무목표에 반복 종료 나이를 넣으면 시작~종료 나이까지 매년 지출(노후 진단·인출에 반영). 처방의 ‘재무목표별 필요 적립액’ 표에는 ‘매년 반복’ 행으로 나오지만, 노후 진단에서도 해마다 지출로 빠지므로 처방의 목적자금 적립 합계와 목적자금 바구니에는 넣지 않음. 이 카드는 빠진 목표(반복 기간이 끝남·목표 나이가 지났거나 0·은퇴 분류)를 이유와 함께 보여 주고, 지난 목표·나이가 빈 목표는 노후 계산에도 들어가지 않는다고 알림
- **연간 현금흐름 흐름도**: 노후 진단의 같은 이름 카드에서 나이(슬라이더 또는 은퇴·소득 시작·일시금·대출 종료 나이 버튼)를 고르면 그 해 1년 동안 들어오는 돈(왼쪽) → 나가는 돈(오른쪽)을 금액에 비례한 굵기의 띠로 보여 줌(오늘 물가, 올해가 몇 달만 남았으면 내년부터). 은퇴 후는 소득·연금 줄마다 + 일시금·매각대금·세액공제 환급 → 생활비·대출 상환·목표 탭 지출·은퇴 후 보험료·국민연금 몫 세금, 은퇴 전은 세후 소득 → 생활 지출(세후 소득 − 대출 상환 − 저축, 보험료 포함)·저축·투자·대출 상환(배우자 소득이 있으면 본인·배우자 줄로 나누고, 배우자가 먼저 은퇴하면 그 해부터 저축과 함께 소득에서도 배우자 몫을 빼 생활 지출이 이어지게). 들어오는 돈이 모자라면 ‘금융자산에서 인출’, 남으면 ‘금융자산에 더함’을 넣어 양쪽 합계를 맞춤(인출과 저축은 상계해 시뮬레이션의 수익 전 잔액 변화와 같은 순액만 한쪽에 표시하고, 은퇴 전 소득이 대출 상환 + 저축보다 적으면 그 차이를 ‘소득 초과 저축’으로 따로 보임). 연금계좌에서 꺼낼 때의 연금소득세·퇴직소득세는 넣지 않음(인출 계획의 연금 세금 점검에서 확인). 그림은 카드 폭에 맞춰 다시 그려 휴대폰에서도 옆으로 밀지 않고 다 보이며, 긴 줄 이름은 줄이지 않고 띄어쓰기·여는 괄호 앞에서 여러 줄로 나눠 씀
- **리밸런싱 금액 계산**: 투자 점검의 같은 이름 카드. 목표 투자형 비중은 직접 입력하고(프로필에 저장), 0이면 투자 성향 권장값을 씀. 금융자산(부동산 제외, 수령 전 묶인 자산 포함) 중 투자형 비중이 목표와 ±5%p 안이면 그대로 두고, 넘으면 넘치는 쪽(투자형 또는 안전형) 자산을 줄이는 금액을 **계좌별로 나눠** 보여 줌. 줄이는 순서는 '바꿀 수 있는 금액에 비례'(기본)와 '연금계좌부터 먼저'(세금 없는 연금계좌를 바꿀 수 있는 만큼 먼저 바꾸고 모자란 만큼만 일반계좌에서 비례로 팖) 가운데 고르고(프로필에 저장), 두 방식에서 일반계좌에서 파는 금액이 얼마나 달라지는지 함께 보여 줌. 일반계좌(연금계좌가 아닌 금융자산)는 판 돈으로 일반계좌의 모자란 쪽 자산을 평가액에 비례해 사고(없으면 새 상품을 사서 자산 탭에 추가하라고 안내), 연금계좌는 자산 탭의 한 줄을 계좌 하나로 보고 판 돈으로 같은 계좌 안에서 반대 성격 상품을 삼(세금 없음, 계좌 사이로 돈이 넘어가지 않음). 이름에 IRP·DC·퇴직이 들어간 퇴직연금 계좌는 투자형을 평가액의 70%까지만 담을 수 있어, 계좌 안 교체만으로 모자란 금액은 '연금계좌 밖으로 빼야 맞춰지는 금액'으로 따로 표시(빼면 연금 외 수령 세금이 붙으므로 보통은 빼지 않는 편이 유리하다고 안내). 수령 연도 전이라 묶인 자산(노란우산 등)은 비중에는 넣되 사고팔 목록에서 빼고, 그래서 맞추지 못하는 금액도 알려 줌. 연금계좌 줄마다 **'자산 탭에 반영'** 버튼: 계좌에서 실제로 상품을 바꾼 뒤 누르면(한 번 확인) 그 자산 한 줄을 남는 줄(원래 성격, 금액만 줄어듦)과 새 줄('계좌 이름 (안전형|투자형)', 반대 성격, 바꾼 금액)로 한 번에 나눠 저장. 과세제외·퇴직금 재원은 금액 비례로 나누고(합계 그대로), 명의·지분·연금수령 1년차·인출 시작 연도·꺼내는 순서·비교 순서 등 계좌 속성은 두 줄에 같게 복사, 새 줄의 기대수익률·변동성은 가진 같은 성격 금융자산의 금액가중 평균(없으면 안전형 3%·0.5, 투자형 5%·10). 새 줄 이름이 원래 이름을 품어 IRP·DC·퇴직 판단도 유지됨. 계좌 전체를 바꾸면 줄을 나누지 않고 성격만 바꿈. 계산한 뒤 자산 탭에서 그 계좌를 고쳤으면 저장하지 않음. 나눈 두 줄에는 **같은 계좌** 이름(원래 계좌 이름)이 들어가 연금 세금·연금수령한도·퇴직금 최소 인출·꺼내는 순서(새 줄이 맨 뒤로 가지 않음, 직접 넣었으면 두 줄 가운데 작은 번호)·이정표·월별 인출 기록·연말결산 이어받기(계좌 이름으로 적은 인출을 두 줄의 재원 비율로 나눠 과세제외·퇴직금 재원을 줄임)를 계좌 하나로 계산. 퇴직연금 70% 한도도 계좌 전체로 보아, 이미 투자형을 담은 계좌는 70%에서 그만큼을 뺀 금액까지만 바꾸라고 함. 같은 계좌에 반대 성격 줄이 이미 있으면 새 줄을 만들지 않고 그 줄로 옮기고, 다 옮기면 남은 줄을 지움. 같은 계좌로 나뉜 줄이 있으면 리밸런싱 카드에도 **한 줄로 합치기** 버튼이 나옴(연금계좌 표에 나온 계좌는 그 줄 밑, 나머지는 카드 아래 ‘같은 계좌로 나뉜 연금계좌’에, 자산 탭과 같은 미리보기·확인창)
- **계획 저장·비교**: 맞춤 처방 화면의 같은 이름 카드에서 지금 입력한 계획에 이름을 붙여 최대 5개까지 저장하고, 60세 은퇴안과 63세 은퇴안처럼 여러 계획을 한 표에서 나란히 봅니다. What-if 슬라이더로 은퇴 나이나 은퇴 후 생활비(인출액 고정 방식이면 월 고정 인출액)를 바꿨다면 그 조정안을 바로 저장할 수 있습니다. 표에는 은퇴 나이, 월 생활비, 금융자산, 순자산, 성공확률(지금 계획 대비 ±%p), 평균 수익일 때 고갈 나이, 첫해 인출률, 기대수명 때 남는 자산(중앙값)이 나오고, 저장한 계획의 값은 오늘 날짜 기준으로 다시 계산합니다. 계획에는 프로필·자산·부채·수입지출·재무목표·보험이 들어가 백업 파일에도 함께 저장되며, ‘불러오기’를 누르면 지금 데이터가 그 계획으로 바뀝니다(순자산 추이·연말결산·월별 인출 기록은 그대로)
- **인출률**: 인출 첫해 자산에서 꺼내는 금액(생활비 − 연금·소득 + 남은 대출 + 그해 지출) ÷ 금융자산. 상한(기본 6%)의 2/3 이하 양호, 상한 이하 주의, 초과 위험
- **가드레일 인출**: 평균수익으로 정액 인출할 때의 연초 자산을 기준선으로, 매년 초 자산이 기준선보다 ±15% 넘게 벗어나면 인출을 10% 줄이거나 되돌림(계획의 70~130%, 기본은 ‘감액만’). 감액 판정선(하단선)은 min(기준선, 필요 자산) × (1 − 15%)이고, 줄였던 배율은 min(기준선, 필요 자산) × (1 + 15%)를 넘으면 1까지 되돌림. 필요 자산[i] = max(0, 그 해 인출 필요액 − 그 해 유입 + 다음 해 필요 자산 ÷ (1 + 평균 실질수익률)), 마지막 해 뒤는 0
- **연말결산**: ‘기준선으로 고정’ 시점의 평균수익·정액 인출 경로와 필요 자산을 물가로 환산해 해마다 12월 말 실제 자산과 비교(표의 하단선은 기준선과 필요 자산 중 낮은 쪽, 필요 자산이 없는 예전 기준선은 기준선만). 판정은 1년에 한 번, 직전 배율에서 이어서 적용. ‘기준선 다시 고정’은 계획 자체를 바꿨을 때만 쓰며, 누르기 전 확인 창에 최근 판정·다음 해 권장 인출·판정에서 빠지는 결산 연도를 지금 값과 나란히 보여 주고, 직전 기준선은 한 단계 보관해 ‘이전 기준선으로 되돌리기’로 돌아갈 수 있음(결산 기록·자산·월별 기록·다른 화면 계산은 그대로)
- **연금 세금**: 계좌 사이에서는 과세제외 → 과세재원(1인 연 1,500만원 안, 연금소득세 5.5·4.4·3.3%) → 퇴직금 재원(퇴직소득세 × 70%, 실수령 11년차부터 60%) → 계좌 밖 자산 → 그래도 모자라면 세율이 낮은 쪽부터 퇴직금 재원 연금수령한도 초과분(퇴직소득세 전액)·과세재원 1,500만 초과분(16.5%) 순으로 꺼냄. 한 계좌 안에서는 법정 순서(과세제외 → 퇴직금 재원 → 과세재원)로만 빠짐. 운용수익은 모두 과세재원으로 쌓이고 과세제외·퇴직금 재원은 명목 금액 그대로(올해가 몇 달만 남았어도 다음 해 표에서 같은 금액). 실수령연차는 퇴직금 계좌에서 실제로 꺼낸 해만 세며 ‘매년 최소 인출’을 넣으면 그 금액을 꺼내 ISA·일반계좌로 옮김. 계좌별 **연금수령한도** = 연초 평가액 ÷ (11 − 연금수령연차) × 120%(11년차부터 한도 없음, 1년차 = 55세·가입 5년이 지난 해). 한도를 넘는 금액은 연금외수령(과세재원 16.5%, 퇴직금 재원 퇴직소득세 전액)으로 보고 경고
- **인출 시작·순서와 한도 채우기**: 계좌별 인출 시작 연도 전에는 꺼내지 않고, 같은 사람 계좌는 ‘꺼내는 순서’대로 꺼냄. ‘꽉 채우기’를 켜면 필요액을 꺼낸 뒤 남은 1,500만 한도·연금수령한도 안에서 과세재원을 더 꺼내 세후 금액을 ISA·일반계좌(같은 수익률로 운용)에 넣음
- **추가 납입**: 납입은 ISA·일반 → (모자라면) 연금계좌 인출 순으로 내고, 공제받은 납입액은 과세재원, 나머지는 과세제외로 쌓음. 세액공제 = min(납입, 900만) × 공제율, 종소세 추정을 켜면 그해 종소세가 한도. 환급은 다음 해 실질 금액으로 유입
- **종합소득세·건보료**: 임대 사업소득 = 임대수입 × (1 − 필요경비율), 공적연금 연금소득금액 = 총연금액 − 연금소득공제(한도 900만), 근로소득금액 = 총급여 − 근로소득공제(한도 2,000만), 근로소득세액공제 = 근로소득분 산출세액(산출세액 × 근로소득금액 ÷ 종합소득금액) 130만 이하 55% · 넘는 부분 30%(한도 총급여 3,300만 이하 74만 · 7,000만 이하 66~74만 · 1.2억 이하 50만 · 그 초과 20만 이상)에 표준세액공제 13만, 근로 원천징수(기납부) = 근로소득만 있다고 본 연말정산 결정세액, 사업소득 = 수입 × (1 − 항목별 필요경비율), 종합소득세 = 2023년~ 누진세율 × 1.1(지방세). 건보료 = (전년 임대·사업소득 + 전년 (공적연금 + 근로소득 총급여) × 50%) × 보험료율 + 재산분(현재 고지서에서 역산, 또는 부동산 자산 과세표준 − 1억의 등급 점수 × 211.5원) × (1 + 장기요양). 국민연금 몫 = 국민연금 때문에 늘어난 종소세(원천징수 뺌) + 건보료 소득분. 국민연금은 입력 월액(세후면 세전으로 환산)이 연 인상률(비우면 물가)만큼 오른다고 보고, 개시 첫해는 출생 월 다음 달부터 월할
- **부부**: 배우자 출생연도·세후 소득·은퇴 나이·국민연금·개인연금을 배우자 나이로 입력하면 본인 나이로 바꿔 계산. 배우자가 먼저 은퇴하면 그때부터 저축 감소, 본인이 먼저 은퇴하면 배우자 은퇴 전까지 배우자 소득을 은퇴 후 소득으로 반영

- **이미 은퇴해 인출 중일 때**: 비상금 개월 수·바구니 권장액·DSR·보험료 부담은 지출 탭과 세후 월소득(은퇴 전 값) 대신 은퇴 후 흐름으로 계산합니다(월 지출 = 은퇴 후 생활비 + 대출 상환 + 은퇴 후 보험료, 월소득 = 지금 들어오는 연금·월세 등, 홈의 월 현금흐름과 같은 금액). 지출이 소득보다 많은 것은 계획된 자산 인출이므로 비상금 점검·처방에서 ‘부족분으로 몇 개월 뒤 바닥’ 경고와 점수 상한을 쓰지 않고 현금성 바구니(앞 1~2년 인출분)를 안내합니다. 목표는 월 적립 처방 대신 ‘인출 계획에 포함됨’ 참고 항목으로 보여 주고, 인출액 고정 방식이면 생활비 대신 **월 고정 인출액**을 얼마로 낮춰야 하는지 역산합니다. - **처방**: 성공확률 목표를 맞추는 저축액·수익률·은퇴나이·생활비를 이분 탐색으로 역산. 하락장 가드레일은 강도별 12개 조합 가운데 목표를 넘고 평생 줄이는 생활비 부담(평균 감축 연수 × 감축 비율)이 가장 작은 설정을 제안하고, 어느 조합도 목표에 못 미치면 가장 효과 큰 설정의 확률을 알려 줌
- **보장 갭**(피보험자별): 보험을 피보험자(본인·배우자·자녀 출생연도별)로 묶어 따로 진단합니다. 본인 사망보장 = 유족 생활비 × 부양기간 + 부채 + 교육비 − 유동자산, 진단비 = 그 사람 연소득(본인 = 가구 소득 − 배우자 소득) × N배(소득이 없으면 3,000만원), 배우자 사망보장 = 배우자 연소득 × 부양기간, 자녀는 진단비 3,000만원만 필요액으로 보고 사망·간병은 가입한 경우에만 표시합니다. 처방전에는 ‘배우자 암·중대질병 진단비 부족’처럼 사람 이름을 붙입니다
- **재무점수(100)**: 저축률 20 · 비상금 15 · 부채 15 · 노후 준비 25 · 분산·적합 10 · 보장 15 (매달 부족분으로 비상금이 줄고 있으면 비상금 점수는 목표 개월 수 안에 바닥날 때 40%, 아니면 60%가 상한)

> 계산 결과는 입력값과 가정에 기반한 참고용 추정치이며, 투자 권유나 금융 자문이 아닙니다.
